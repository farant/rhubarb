====================
Last updated: 2026-08-13

A C89 monorepo for building catholic civilization.
All identifiers in Latin. No dependencies. Long-term thinking.

APPLICATIONS  (apps/ - NOT swept by any test runner; see note)
-----------------------------------------------------------

    apps/forum/   writing world: pipata, articuli, res (user-defined
                  genera), scholia, tags. Talks to tabulariumd.
    apps/villa/   remote server administration. UI is a V4b
                  placeholder; ALL logic lives in lib/villa_agens.c
                  so probationes/probatio_villa_agens.c can gate it.

    CAUTIO: no runner sweeps apps/. Anything that must not rot
    belongs in root probationes/. apps/forum/fumus.sh is referenced
    by nothing and must be run BY HAND (it is, however, the only
    gate the forum UI has -- it drives a real window and asserts
    DOM structure, so it is worth running after any index.html edit).

    apps/forum/forum.sh regenerates the capsula before building
    (fixed 2026-07-25). Before that, every index.html edit was
    invisible until capsula_generare was run by hand -- and
    fumus.sh pre-builds THROUGH forum.sh, so the smoke harness was
    silently testing a stale UI.

KEY PATTERNS
------------

Memory:     piscina (arena) ──► all allocations tied to arena lifetime
                               mark/reset with PiscinaNotatio
                               no manual free()

Strings:    chorda = {i32 mensura; i8* datum}
            NOT null-terminated! Never use strcpy/strlen/etc.
            Use internamentum for deduplication

Data:       nuntium ──► protobuf-style binary (compact, typed)
            nuntium_schema ──► schema language for nuntium messages
            json/xml/toml/stml ──► text formats

Entity:     entitas ──► properties with typed values
            entitas_repositorium ──► event sourcing storage
            persistentia ──► memory or file backend

Records:    tabularium ──► append-only JSONL ledger (gesta/) behind the
                           tabularii MCP; the project board lives here,
                           not in prose


BUILD
-----

Compiler:   C89 strict
Flags:      THE AUTHORITY IS compile_tests.sh, NOT THIS LIST.
            -std=c89 -pedantic -Wall -Wextra -Werror -Wconversion
            -Wsign-conversion -Wcast-qual -Wstrict-prototypes
            -Wmissing-prototypes -Wwrite-strings
            -Wno-long-long -Wno-overlength-strings
            The last three are load-bearing and were missing here
            (and in root CLAUDE.md) until 2026-08-13: latina.h makes
            i64/s64 `long long`, and any file embedding a big string
            literal (vitrea's JS shim, ~1380 chars vs C90's
            guaranteed 509) needs -Wno-overlength-strings. Copying
            the short list costs two failed builds.

Scripts:    ./compile_tests.sh <pattern>  ── run tests matching pattern
            ./compile_tools.sh            ── compile all tools
            ./compile_library.sh          ── compile library
            (subprojects have their own ./compile_probationes.sh)


NOTES
-----

- All code in Latin (identifiers, comments, messages)
- "nomen" is a macro for typedef, don't use as variable name
  (every word #defined in latina.h is a reserved identifier)
- Platform: macOS only (platform layer exists for future porting)
- Tests use credo.h framework (see probationes/probatio_piscina.c)
- Worklogs: lib/foo.worklog.md for non-obvious decisions
