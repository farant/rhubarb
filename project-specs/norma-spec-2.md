# norma spec 2 - the STML face and the C it compiles to

Born 2026-10-08 (Fran, right after norma v1 merged to main at 673d8111:
"do we have any kind of json object -> schema stuff? it might also be
worthwhile to think about data driven schema which might be written in
stml"). Ledger desideratum …MPPK82 (follows …EN4B, norma v1, impletum).
Brainstorm decisions, all Fran's:

- C builders and `.norma` STML are "two different interfaces to the
  library for different needs" - split by API, no ownership rule.
- `.norma` is authoritative where it is used; binaries that ship a
  schema get it as GENERATED C builder calls (approach (a)), not as
  embedded STML bytes - no floating files, no stml parser in every
  consumer.
- Enum values as one attribute `electio="a b c"`, `<licitum>` children
  as the escape hatch for values with whitespace.
- `requiritur` defaults to true.
- The API shape of §III, including the additive core change for
  generator names.
- Inference (JSON samples -> schema) is slice B, its own spec, after
  this slice settles.

*The question: how does a schema written as data become, with no loss
and no drift, the same `Norma*` the C builders make - readable at
runtime when the need is dynamic, compiled into C when a binary ships
it?*

## I. Framing

Four pieces, each depending only on what is below it:

| Piece | Depends on | Job |
|---|---|---|
| `norma` (core, exists) | json, sors | + one additive change (§III.1) |
| `norma_stml` | norma, stml, canon | read `.norma` -> `Norma*`; write `Norma*` -> `.norma` |
| `norma_ad_c` | norma (visus only) | `Norma*` -> generated `.h` + `.c` text |
| `tools/norma.c` -> `bin/norma` | all three | CLI: `norma c ...` (fabrica's generator), `norma iudicare x.norma valor.json` |

The core never learns STML exists: vates and every other builder user
keep linking only `norma`. The canon is the floor, the loader the
judgment ("canon fundamentum praestat, non sapientiam", `canon.h`).

## II. The dialect

### II.1 Shape

```
<normae versio="1">

  <norma titulus="#usus" (>
    <objectum modus="notandum" ((>
      <campus titulus="input_tokens" (> <integer minimum="0"/>
      <campus titulus="cache_read_input_tokens" requiritur="falsum" (> <integer minimum="0"/>

  <norma titulus="#responsum" (>
    <objectum modus="notandum">
      <descriptio(> Responsum /v1/messages (status 200).
      <campus titulus="id" (> <textus longitudo_minima="1"/>
      <campus titulus="stop_reason" (> <textus aut_nullum="verum" electio="end_turn tool_use max_tokens"/>
      <campus titulus="usage" (> <ad norma="#usus"/>
      <campus titulus="content" (> <tabulatum(>
        <discrimen clavis="type" modus="notandum">
          <variatio valor="text" (> <objectum(>
            <campus titulus="text" (> <textus gignens="sententia"/>
          <variatio valor="tool_use" (> <objectum(>
            <campus titulus="input" (> <liberum/>
        </>
    </>
</>
```

### II.2 Rules

- Root `<normae versio="1">`; children are `<norma titulus="#x">`, each
  with exactly one type child. A named norma is BOTH exported (the
  loader returns it by name) AND referable (`<ad norma="#x"/>`). No
  separate definitions block.
- Type elements, one per `NormaGenus`: `liberum nullum boolean integer
  numerus textus tabulatum objectum discrimen`, plus `ad`.
  - `tabulatum`: exactly one type child.
  - `objectum`: `<campus>` children; `campus` has `titulus` (canon
    genus `textus` - JSON keys are anything: `"a.b"`,
    `ephemeral_5m_input_tokens`) and exactly one type child.
  - `discrimen clavis="type"`: `<variatio valor="...">` children, each
    with exactly one `objectum`.
- Modifiers (attributes unless stated):
  - all types: `aut_nullum` (veritas), `gignens` (nomen), optional
    `<descriptio>` child (first child).
  - `integer`: `minimum`, `maximum` (canon numerus).
  - `numerus`: `minimum`, `maximum` as canon textus - the loader parses
    them as f64 (floats allowed).
  - `textus`, `tabulatum`: `longitudo_minima`, `longitudo_maxima`.
  - `textus`: `forma`, `electio="a b c"` (split on ASCII whitespace),
    or `<licitum>` children for values containing whitespace - not both.
  - `objectum`, `discrimen`: `modus` = `clausum | apertum | notandum`
    (default clausum, as in the core).
  - `campus`: `requiritur` (default `verum`; the writer omits it then).
- Cycles through `<ad>` are refused with the reference chain named
  (core recursion is "nondum").
- No STML templates in v1: the loader judges the plain tree, so every
  `linea:columna` points at what the author wrote. Expansion is a
  named future (§VII).

### II.3 Who judges what

canon (`norma.canon`) first: closed vocabulary, child cardinality,
attribute genera, required attributes, `#` sign syntax. If canon finds
anything, the loader stops there (a malformed tree only yields noise).

The loader then judges:

| Class | Example |
|---|---|
| float bound unparsable | `<numerus minimum="1,5"/>` |
| bounds inverted | `minimum="10" maximum="2"` |
| modifier on wrong type | `forma` on `integer`, `electio` on `boolean` |
| electio and licitum both | `<textus electio="a"><licitum>b</licitum>` |
| electio empty | `electio="  "` |
| reference unresolved | `<ad norma="#nemo"/>` |
| reference cycle | `#a -> #b -> #a` |
| name duplicated | two `<norma titulus="#x">` |
| gignens unknown | name absent from a SUPPLIED registry |

Every class is an error except `gignens` with NO registry supplied:
that is a NOTE and the name is kept (§III.1).

## III. API (shape - exact headers go to Fran first, task A0)

### III.1 Core, additive

- `NormaVisus` gains `chorda gignens_titulus`.
- New builder `norma_gignens_titulus(Norma* n, constans character*
  titulus)`: records the name; the function may stay NIHIL.
- `norma_gignere` on a node with a name but no function falls back to
  the default generation of its genus - same output as no gignens.
- No existing behaviour changes; v1's tests stay as they are.

### III.2 `norma_stml.h`

```c
nomen structura { chorda titulus; NormaGignens functio; vacuum* datum; } NormaGignensNominatum;
nomen structura { i32 linea; i32 columna; chorda nuntius; } NormaStmlVitium;
nomen structura { chorda titulus; Norma* norma; } NormaNominata;

nomen structura {
     b32  successus;
     Xar* normae;    /* NormaNominata, document order; empty on failure */
     Xar* vitia;     /* NormaStmlVitium: canon's first, then the loader's */
     Xar* notae;     /* gignens kept by name, no registry */
} NormaStmlLectio;

NormaStmlLectio norma_stml_legere(chorda fons,
    constans NormaGignensNominatum* gignentes, i32 numerus_gignentium,
    Piscina* p);
Norma*  norma_stml_quaerere(constans NormaStmlLectio* l, constans character* titulus);
chorda  norma_stml_scribere(constans NormaNominata* normae, i32 numerus, Piscina* p);
```

- All-or-nothing: `successus = FALSUM` -> `normae` empty, ALL errors
  reported (not the first).
- `norma_stml_quaerere` takes the bare name (`"responsum"`, no `#`).
- The writer emits canonical form = `stml_scribere(..., VERUM)` output
  (so `stml formare -probare` passes on anything it writes). Defaults
  are omitted; `electio=` is chosen when no value contains whitespace,
  `<licitum>` children otherwise.
- DAG kept: a node pointer-equal to a named norma being written (other
  than the one at that root) is written as `<ad norma="#x"/>`.
- The writer refuses (empty chorda + reason through a `chorda* causa`
  parameter or equivalent, settled in A0) a node whose gignens has a
  function but no name - writing it would lose information.
- `norma.canon` is EMBEDDED via capsula (GENERATUM, judged by fabrica),
  and also registered in `canones.registrum` for `.norma` so house
  tooling judges the files.

### III.3 `norma_ad_c.h` and `bin/norma c`

```
bin/norma c lib/vates_responsum.norma -praefixum vates_norma_ \
    -caput include/vates_responsum_norma.h -corpus lib/vates_responsum_norma.c
```

- One function per named norma: `Norma* vates_norma_responsum(Piscina*)`,
  `Norma* vates_norma_usus(Piscina*)`.
- Each `gignens="sententia"` becomes an `extern` declaration of
  `vates_norma_gignens_sententia` (an `NormaGignens`), passed to
  `norma_gignens` and named with `norma_gignens_titulus`. The consumer
  defines it; the LINKER checks it.
- Shared references -> one local per construction call (the DAG
  survives into C); references across named normas call a static
  builder once per call.
- Both files GENERATUM on line 1; declared to fabrica as a generator
  action (inputs: the `.norma`, `bin/norma`'s sources); judged by
  `generata`. aedilis's `include/X.h -> lib/X.c` rule links them.

## IV. Testing - five oracles, each born red

1. **Byte round trip.** `scribere(legere(x)) == x` over the fixture
   corpus (`probationes/fixa/norma/*.norma`), asserted over TWO cycles
   (memory: one write-read cycle is not evidence).
2. **Builder corpus.** Schemas built in C -> write -> read: same JSON
   Schema export, and same judgments (vitia + notae: path and cause)
   on samples from `norma_gignere` in TYPICA, FINES and INVALIDA.
3. **Emitter vs loader.** The fixture corpus emitted to C (GENERATUM,
   committed under `probationes/fixa/norma/`, judged by `generata`)
   and compiled into the test: same export and judgments as the loader
   on the same `.norma`.
4. **Error coverage.** One fixture per class of §II.3 (and per canon
   class the dialect can trigger); a coverage bitmask asserts every
   class fired.
5. **Formatter lint.** `stml formare -probare` passes on every
   committed `.norma`.

Plants (each must COMPILE and turn its oracle red, then be restored):

| Plant | Oracle that must go red |
|---|---|
| writer drops `requiritur="falsum"` | 1, 2 |
| loader ignores `modus` | 2 |
| writer inlines shared nodes | 1 |
| emitter swaps minimum/maximum | 3 |
| one error class silently skipped | 4 |

## VI. Done means

- A `.norma` file reads to the same `Norma*` (by export and judgment)
  that the builders make, writes back byte for byte, and compiles to C
  that agrees with both.
- vates' response schema lives in `lib/vates_responsum.norma`; the
  binary carries it as generated C with no STML dependency.
- All five oracles green, every plant seen red.

## VII. Not in this slice

- **Inference** (`norma_inferre`, JSON samples -> draft `.norma`):
  slice B, own spec. Doctrine already fixed by `natura/natura.canon`'s
  header: "numeri OBSERVATI non sunt numeri POSTULATI" - inferred
  schemas are drafts for review (NOTANDUM default, required = seen in
  every sample, enums and bounds opt-in).
- STML templates inside `.norma` (canon_iudicare_expansum exists; the
  cost is `linea:columna` pointing into expansions).
- Recursive schemas (core "nondum").
- Struct binding (norma v1 §VII).
- A declared-vs-inferred diff tool (needs slice B).
