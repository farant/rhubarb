status: open

related: []

D106 falsifies topological entropy as a predictor for computation in algebraic reservoirs. The crossover analysis claims that derived series depth and solvability are the correct measures — algebraic complexity predicts computation where dynamical complexity is completely orthogonal. This is described as a publishable refinement of the Edge of Chaos thesis. The question can be tested: across all 109 DKC demos, compute both topological entropy and derived series depth for each algebra, then correlate with computational capability (max XOR, parity reachability). If algebraic complexity is strictly superior, it's a clean result. If both contribute, the relationship is more nuanced.
