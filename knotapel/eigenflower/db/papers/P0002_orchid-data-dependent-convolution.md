## Key Contributions

Orchid replaces the self-attention mechanism in Transformers with a data-dependent global convolution layer. The convolution kernel is generated dynamically by a small conditioning neural network that processes the input sequence, making it "data-dependent" (like attention) while maintaining O(L log L) complexity via FFT (vs O(L^2) for attention).

## Key Techniques

- **Data-dependent convolution**: y = h_theta(x) * x, where h_theta is a neural network generating the kernel from input. Kernel adapts to data, giving attention-like expressiveness.
- **Shift-equivariance preservation**: Two conditioning designs: (1) Phase Suppression -- take |F(Conv1d(x))| to eliminate phase; (2) Cross-Correlation -- compute cross-correlation between two shift-equivariant mappings.
- **Chain of order 1.5**: Two element-wise multiplications sandwiching one data-dependent convolution. Cascade of circulant and diagonal matrices approximates dense linear layers.
- **Static positional bias**: h = h_theta(x) + h_0, combining data-dependent and position-dependent information.
- **Block-diagonal MLP replacement**: 4-block diagonal matrices replace dense MLP, reducing parameter count significantly.
- **DCT outperforms DFT**: Orthonormal DCT works better for the conditioning network.

## Specific Relevance to Eigenflower

- **Efficient sequence mixing**: O(L log L) via FFT means much faster training and inference than attention. Apple's Accelerate framework has vDSP_DCT and FFT directly usable for C89 implementation.
- **Parameter efficiency**: 30% fewer parameters for same/better performance -- critical for fitting in M2 memory.
- **Diffusion compatibility**: Orchid's bidirectional global convolution suits diffusion text generation (denoises entire sequence simultaneously).
- **Not yet autoregressive**: Paper notes Orchid is not inherently compatible with causal/autoregressive models. Limitation for GPT-style generation but fine for BERT-style or diffusion.

## Key Results

- Orchid-BERT-base (77M params) outperforms BERT-base (110M params) on GLUE by 1.0 points
- Orchid-BERT-large (254M) outperforms BERT-large (340M) by 0.6 points
- Handles associative recall at 131K token sequences where Transformers fail
- Orchid-ViT achieves 80.2% Top-1 on ImageNet-1k with 48M params (ViT-b: 87M for 78.5%)

## Combinability Notes

- **Orchid + BitNet**: Convolution kernel itself could be ternary {-1, 0, +1}, meaning add/subtract in time domain (no FFT needed for sparse ternary kernels).
- **Orchid + TRM recursion**: O(L log L) convolution makes each recursion step cheaper than attention.
- **Orchid conditioning as meta-reasoning**: The conditioning network that generates the kernel is a meta-network deciding HOW to process input -- analogous to syllogistic reasoning selecting which rules to apply.

## Implementation Notes

- Conditioning network: 1D depthwise Conv1d (kernel 3-5) + frequency-domain Conv1d
- Frequency transform: Orthonormal DCT preferred
- Code: https://github.com/Karami-m/orchid (PyTorch)
- Key sizes: Orchid-s (735K for CIFAR), Orchid-BERT-base (77M), Orchid-BERT-large (254M)
- Trained on single P100 for small tasks; 4xA100 for BERT pre-training
