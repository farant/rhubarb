The Domingos tensor logic formula is SP[s,p] = H(SM[s,m] * MP[m,p]) where H is a step function (Heaviside). DKC shows that activation choice is critical — the activation determines capability (D50), and the parity-lock theorem (D92) proves that encoding determines accessible function space. For syllogistic logic, the step function needs to correctly map tensor products to truth values across all valid syllogistic forms (Barbara, Celarent, Darii, etc.). Whether Heaviside is the right choice, or whether different syllogistic figures require different activation functions, is unexamined. DKC's k-sector partition activations offer a richer alternative that might encode the four categorical proposition types (A, E, I, O) more naturally than binary Heaviside.
