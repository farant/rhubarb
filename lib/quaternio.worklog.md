# quaternio worklog

## 2026-10-08 - v1 (Q2)

Quaternions over any commutative `Anulus`, ring-generic exactly like
`Matrix`: `Quaternio {anulus, partes}` with the four parts as ring
elements, results in the caller's pool, mixed rings refused (FALSUM).
API approved by Fran 2026-10-08 ("that looks like a good design to me and
the flag makes sense"); the flag is `antipodes_idem` on
`quaternio_proximus`. Motivation: the knotapel demos D66-D97 did
icosians, group closure, axis dedup and Voronoi cells in doubles with
epsilons; over Q(sqrt 5) (`extensio`) all of it is exact.

Design points:

- Hamilton product as two 4x4 tables (`signa`, `ordo`): component k of
  pq is sum_m signa[k][m] p_m q_ordo[k][m]. `_summa` is the one helper
  (signed sum of four products); the norm is the same helper with all
  signs +1 and x = y.
- ROTATIONS STAY IN THE RING: q v conj(q) = N(q) R(v), so a Lipschitz
  (integer) quaternion gives an integer rotation without division.
  `quaternio_matrix` returns N(q) R (columns = images of i, j, k), not R.
  Only `quaternio_inversum` divides, and only over a field (`corpus`).
- EXACT GEOMETRY WITHOUT SQUARE ROOTS:
  - `eadem_rotatio`: p = s q <=> all 2x2 minors of (p; q) vanish (over a
    domain). q and -q are the same rotation automatically. Over Z/n
    (not a domain) "minors vanish" is weaker than proportional; rotation
    language is meaningless there anyway, so not guarded.
  - `eadem_axis`: cross product of vector parts = 0 (both directions).
  - `compara_angulum`: cos^2(theta/2) = a^2/N, theta in [0, pi], so
    theta_p > theta_q <=> a_q^2 N_p - a_p^2 N_q > 0. Needs ORDER: uses the
    new `anulus->signum` hook (lib/anulus.worklog.md, same day); NIHIL
    hook -> FALSUM.
  - `proximus`: max cos = (v.u)/(|v||u|); |v| is common, and x -> x|x| is
    monotone, so compare s_k (v.u_k)^2 |u_o|^2 against s_o (v.u_o)^2
    |u_k|^2 with s = sign(v.u) (s = +1 when antipodes_idem: axes without
    direction). Strict > keeps the FIRST index on ties (documented, and
    tested: the plant "last index on ties" is red).
- Text "[a, b, c, d]" via the ring's own ad_chordam/ex_chorda; split on
  commas, so it assumes no ring prints a comma inside one element (true
  for Z, Q, Z/n, Z[t], extensio today).

Tests (probationes/probatio_quaternio.c, 55, ~0.3 s):
- Hamilton table (ij = k, ji = -k, ... i^2 = j^2 = k^2 = ijk = -1).
- 100 random Lipschitz quaternions (sors): N(pq) = N(p)N(q),
  associativity, conj(pq) = conj(q)conj(p), q conj(q) = N, M M^T = N^2 I,
  det M = N^3, rotare = M v.
- Inverse over Q; refusals (Z is not a field, zero quaternion).
- GROUP CLOSURE as the oracle: binary tetrahedral over Q generated by i
  and [1/2, 1/2, 1/2, 1/2] = 24 elements; [3/5, 4/5, 0, 0] (a rotation by
  an irrational multiple of pi) does not close within the bound of 100
  (count 0 = "not finite");
  binary icosahedral over Q(sqrt 5) generated by i and
  [(a+1)/4, (a-1)/4, 1/2, 0] = 120 elements. These counts are classical
  (|2T| = 24, |2I| = 120), independent of this code.
- Geometry: same rotation (q vs -2q true, a changed part false, zero
  refused on EITHER side), same axis (i vs 3 - 5i true, i/j, i/k, j/k
  false, a pure real refused), angle comparison, proximus with and
  without antipodes, the tie, refusals (Z[t] has no order, zero v,
  numerus 0).

Plants (12, scratchpad runner with the memory watchdog): Hamilton sign,
conjugate keeps the vector, matrix sign, norm sign, inverse without
division, axis minor (b,d) skipped, angle comparison reversed, antipodes
ignored, last index on ties, only three parts parsed, mixed rings
accepted, zero rotation on the right accepted - ALL RED. Q12 first
SURVIVED: the suite only tested a zero LEFT argument of eadem_rotatio;
added the mirrored check. Q4's anchor was ambiguous (the all-plus
`signa` literal also lives in `_productum_scalare`); re-anchored on the
following line.

venenum: quaternio added to tools/venenum_probare.sh (it resets no pool
itself, but drives extensio/matrix over Q(sqrt 5) under ASan/UBSan).

## 2026-10-08 - review Q1 (recensor, RECENSIO_Q1.md)

Verdict: no wrong result (104,903 differential checks over Z, Q, Q(sqrt
2/3/5) with an independent basis-table oracle and 120-digit cosines; the
Hamilton tables and N R derived independently). Findings and fixes:

- M1 (exitus half-built on FALSUM): add/sub, multiplica, scalari,
  conjugatum, inversum, ex_chorda and matrix wrote `exitus->anulus` and
  partes before a loop that can refuse. Now built into a local
  `effectus`, assigned only on success (header states the contract).
  Tests: a Q(sqrt 5) quaternion carrying one element of a SECOND
  Q(sqrt 5) at index 2 makes each operation refuse mid-loop; a sentinel
  exitus (NIHIL, NIHIL) and a sentinel Matrix must stay untouched.
- P (caller-pool garbage): proximus over 118 icosian directions left
  ~390 KB per call (39 GB for a 10^5-point Voronoi pass). The four
  answer-only functions (eadem_rotatio, eadem_axis, compara_angulum,
  proximus) are now thin public wrappers: piscina_notare, the old body
  (`_proximus` etc.), piscina_reficere. Safe because they return only
  b32/s32/index and no ring hook caches into the caller pool (extensio
  writes its field struct only in the constructor). Test: usage before
  and after == equal. GOTCHA: credo records into the SAME pool, so the
  answers are collected into locals and both usage readings are taken
  before any CREDO. venenum stays green (rolled-back bytes are 0xA5, so a
  result read after the reset would break the suite).
- _summa: two alternating accumulators instead of a new buffer per term
  (6 -> 3 per component). Not pursued: precomputed |u_k|^2 for proximus
  (API change; with the rollback the cost is time only, ~0.3 ms per call
  over 118 directions).
- Test vacuity, 8 surviving mutants, all now planted and RED: real parts
  in v.u (every proximus test had a = 0; the demo's icosians do not -
  now directions [100, 2, 1, 0] / [-100, 2, 1, 0]), zero direction
  accepted (+-1 lies in 2I), foreign-ring direction, eadem_rotatio
  minors with index 0 only / adjacent only ([0,1,1,0]~[0,1,2,0],
  [1,0,1,0]~[2,0,1,0]), compara_angulum with zero, eadem_axis pure real
  on the RIGHT (same blind spot as Q12), Z inverting a unit (the old Z
  test used N = 2, refused by the division anyway).
- LOW docs: foreign elements accepted by ex_partibus (later ops refuse)
  and the no-comma assumption for ring text now in quaternio.h.

Plants: 23 (12 original + 8 survivors + M1 x2 + rollback removal), all
red; M1b (matrix_nulla into exitus) goes red by a crash on the success
path, not an assertion. Suite 82 checks.
