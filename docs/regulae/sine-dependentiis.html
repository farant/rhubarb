Sine dependentiis

Write our own libraries instead of using 3rd party dependencies

A project-wide regula: a commitment, kept or broken, across every project. Like every regula it answers conditions, and has exceptions where it was weighed against something else.

What it answers

  • principiumDependencies are entropy deliberately admitted. Programs are machines that do not wear out, unless you opt in to entropy through dependencies (Fran, CLAUDE.md; also the ledger's house principle, "dependentiae sunt entropia consulto admissa").
  • principium"Nobody vendors these libraries to swap them later; they vendor them because rewriting looked impossible." text stack X10
  • occasioAI-assisted volume changes what one person can carry: the difficulty of much library work "is care, not invention". So rewriting no longer looks impossible. text stack X9
  • regulaIt leans on R1, 1.0 and done: "when the release is final and the code owned, the option value of a swappable upstream is worth nothing, and the cost of every seam is paid forever." text stack X10.1

The first is a fused statement in its ledger form (condition and commitment in one sentence); split, the condition is the principium and this page is its commitment.

What it costs

Owning a library means no swapping a half for its upstream later, and a great deal of exacting code; for the text stack alone, roughly 60–100k lines, plus a quality tier no test suite can judge text stack X6.
