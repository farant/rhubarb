norma_gignere

valores JSON ficti ex schemate (norma-spec par. IV)

Fake JSON values from a norma schema, in three modes: typical (plausible), limits (every bounded node at an edge) and invalid (a typical value with exactly one planted violation, whose path and cause are returned). Seeding is per path: each node draws from a stream derived from the hash of its path, and a field's presence from a stream of its own, so adding a field never changes its siblings' values or whether later fields appear. The values come from fictio (names, dates, uuids, real Latin; the limits mode takes its text from the drawer of difficult strings), and a field may name its own generating function. The proof is a mutual oracle between generator and judge. Over 300 seeds and two schemas every typical and limit value, written out and read back, must validate, and every invalid one must produce exactly one issue at the stated path with the stated cause. Coverage is asserted as well: all ten kinds of violation must actually have been exercised, because a green that could mean 'never tried' is not accepted. Written 2026-10-08. Its users so far are tests: the equivalence proofs for norma_stml and norma_ad_c generate values from both sides and compare the judgments.
