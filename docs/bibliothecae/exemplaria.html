exemplaria classica Mac 8x8 (1 bit), communia

The 38 classic Macintosh patterns, 8x8 and one bit deep (solid, dots, checkerboard, bricks, weave and the rest), as a shared table. It lived inside lib/delineare.c until 2026-10-09, when vicus needed a pattern for its focus indicator and the rasterisers of command lists had to reach it too; it was moved out verbatim, and delineare now reads it through this header. A pattern is eight bytes, one per row, the top bit being the leftmost pixel. exemplar_obtinere returns the bytes, and exemplar_punctum answers one pixel at any coordinates, tiling modulo 8 so that negative coordinates wrap correctly. Used by delineare and by the pictor and scriba libraries. The worklog leaves a note for the next extraction of this kind: three build lists outside the root suite are written or generated separately, and each needed the new file.
