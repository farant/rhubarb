Matrices EXACTAE super anulum (anulus.h)

Exact matrices over any ring described by anulus: Z, Q, Z[t, t^-1], Z/p. Build, then freeze: matrix_pone only while constructing, and every operation returns a new matrix. Determinant, rank and kernel come from one fraction-free elimination (Bareiss), in which every division is exact by Sylvester's identity; the kernel uses a fraction-free Gauss-Jordan so that its entries are minors and not products of pivots (a review measured 6326 digits falling to 607). Over a Euclidean ring, which today means Z, there are Hermite and Smith normal forms with optional unimodular certificates (H = UA, D = UAV), and matrix_reticulum_nuclei, a true lattice basis of the integer kernel. The normal forms bring the smallest pivot up and reduce the rest modulo it, never Bezout row combinations: the Bezout version took 22 seconds on a 36 by 36 matrix that Euclid does in 11 ms. Elimination runs in internal scratch arenas and only the result lands in the caller's piscina. A termination bug here hangs where another bug would fail, so the normal-form tests run first under a watchdog. Over Z[t, t^-1] an operation can refuse a well-defined result when an intermediate exponent leaves polynomium's range, and the header says so. First real use: Alexander polynomials as det(V - tV^T) of Seifert matrices. Used by laqueus, extensio and quaternio. Born 2026-10-06.
