icones

Icones macOS (.icns, .iconset) ex una imagine.

Makes macOS app icons from one image: every required size, written as an .iconset directory of PNGs and as a single .icns file. fasciculum (app bundles) could name an icon but not make one; this closes that. It takes an already decoded Imago, so its closure is imago_typus, imago_png and flatura, all the house's own (stb_image lives in the command-line tool, not here). Every refusal names the field, size or path at fault. The cropping mode is an enumeration with one value so that parked options can be added without changing the signature.
