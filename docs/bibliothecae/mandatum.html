mandatum

Mandata delineandi: sex primitiva et index eorum

Drawing as data: a list of six primitives (group, rectangle, line, polygon, image, text) that a program emits instead of touching pixels. Only groups nest, and clip, translation and integer scale are properties of the group, not push/pop commands, so an unbalanced stack is impossible by construction. Colours stay symbolic (a thema role, a palette index, or literal RGBA) and images stay names; only a rasterizer resolves them. A group can carry the id of the component that drew it, for inspectors. The list lives in memory as typed structs in a Xar; STML is its serialization, used for snapshots, inspection and replay expectations, and mandata_aequalia lets a test compare what was drawn rather than pixels. The ludus brainstorm calls this list the GPU-later seam: today it has two consumers, delineare_mandata (pixels) and tessellatio (terminal cells).
