mandatum

Mandata delineandi: sex primitiva et index eorum

Drawing as data: a list of six primitives (group, rectangle, line, polygon, image, text) that a program emits instead of touching pixels. Only groups nest, and clip, translation and integer scale are properties of the group, not push/pop commands, so an unbalanced stack is impossible by construction. Colours stay symbolic (a thema role, a palette index, or an RGBA value) and images stay names; only a rasterizer resolves them. The RGBA value is in the pixel buffer's own packing and not a literal 0xRRGGBBAA: the header said the literal form until 2026-10-06, when the first screenshot of the terminal showed a blue cell as near-white and both rasterizers turned out to read the other order, a belief the passing test had shared. A group can carry the id of the component that drew it, for inspectors. A filled rectangle can take one of the classic 8x8 patterns (exemplaria) instead of a solid fill, anchored to the buffer's coordinates so that neighbouring fills line up; it was added for vicus's focus indicator. The list lives in memory as typed structs in a Xar; STML is its serialization, used for snapshots, inspection and replay expectations, and mandata_aequalia lets a test compare what was drawn rather than pixels. The ludus brainstorm calls this list the GPU-later seam: today it has two consumers, delineare_mandata (pixels) and tessellatio (terminal cells). Born 2026-09-04, with componens and derivare among the first ludus modules.
