arbor_lexema

arbor v1's C89 lexer: turns source into tokens and keeps the trivia (spaces and comments) before and after each one, so the file can be written back byte for byte, an aim every later parser kept. Tracks which standard each token belongs to (C89, C99, extension) and uses 1-based lines and columns as editors do. Everything in an arena. January 2026.

Archived: a frozen predecessor in archivum/, kept as read-only historical reference. It is not built, tested or formatted; see archivum/CLAUDE.md.
