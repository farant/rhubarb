Tabulae GENERATAE runarum (runae)

The layout of runae's generated tables, shared by the generator (tools/runae_generare.sh) and the library: a two-stage table, where the first stage maps each block of 256 codepoints to a block in the second, and identical blocks are stored once. Each byte packs a width (2 bits), a grapheme break class (5 bits) and whether the rune is an emoji variation base (1 bit). The break classes fold Grapheme_Cluster_Break, Indic conjunct breaks, Emoji_Modifier and Extended_Pictographic into one alphabet, which the generator asserts is safe for Unicode 15.1. The header is hand-written and stable; lib/runae_tabulae.c is generated. A standard technique (ICU and most Unicode libraries use a multi-stage table) made explicit enough that a reader can check the bits by hand.
