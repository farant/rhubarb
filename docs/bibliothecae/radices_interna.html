radices_interna

INTERNA radicum: apices piscinarum temporariarum.

The test-only side of radices, not API: only lib/radices.c and the tests include it, and its names carry the genitive prefix radicum_ to set them apart from the public radix_ and radices_. It exposes the high-water marks of the library's private scratch arenas since the last reset, one for the isolation stack and one for the working arenas. It exists because of a review finding: the memory test measured only the caller's arena, where the gain from resetting the scratch arenas is invisible, and three planted faults that each removed a reset stayed green, one of them raising a degree-89 isolation from 38 MB to 1.05 GB. With the marks the test bounds the scratch memory of a degree-59 isolation tightly (byte counts are deterministic), and all three plants are red.
