Terminalis POSIX: modus crudus, lectio cum mora,

The POSIX terminal itself, beneath the pure terminal event source: raw mode (like tessera's bridge, keeping only the suspend signal, so Ctrl-Z really suspends and restores the terminal while Ctrl-C and Ctrl-\\ arrive as ordinary keys), reads with a timeout, writes that retry, and the size in cells and pixels (zero pixels when the terminal does not say, as Terminal.app does not; 80x24 if the query fails). The mode bytes to enter and leave come from the caller and are COPIED, so signal handlers and atexit can restore the terminal with async-signal-safe calls only. One terminal per process. Eventus phase B, October 2026.
