color

The first generation's colour value: an RGBA struct with constructors from components, from a palette index (the Aquinas palette) or from a packed pixel, conversion to the window's pixel format (ABGR on macOS), component accessors and interpolation. Kept for the old views; the newer code names colours by theme role (thema) or carries them in the drawing commands (mandatum).
