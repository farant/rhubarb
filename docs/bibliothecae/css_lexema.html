css_lexema

A total lexer for CSS (the vocabulary of CSS Syntax Module Level 3), the first of three web-format lexers written under silva's contract: TOTAL (any byte sequence lexes; nothing is lost, nothing breaks; a truncated token gets a named INCOMPLETE kind), BYTE-FAITHFUL (emitting the tokens gives back exactly the input, for ANY input), positions in bytes plus 1-based line and column, and trivia as tokens (unlike the spec, which swallows comments, because fidelity and comment queries need them). Escapes are kept verbatim; cooking values is the tree's job. Used by the css client on materia (css_arbor). August 2026; spec project-specs/css-html-js-spec.md.
