eventus

The vocabulary of input, with no window behind it: event kinds, logical keys and W3C physical key codes, modifiers by side, text and IME composition, drops, capability flags, the drags derived from raw mouse events, and EventusNotatum (an event with its notes). Time is data inside the event (milliseconds), never a clock call, so a stream of events can be recorded and replayed exactly. Cut verbatim out of fenestra.h on 2026-10-01 and marked <aedilis nexus="purus"/>, which makes aedilis refuse any link closure that pulls in a framework. That is what lets the ludus interaction core (dispensator, derivare, destinatio, actio, eventus_stml) build and be tested with no Cocoa at all; fenestra.h includes it, so window code sees the same types. Types only, no implementation file of its own; eventus_cauda, eventus_conformitas and eventus_stml build on it (queueing, conformance checking, STML transcripts). Narrative in lib/eventus.phase-log.md, spec project-specs/eventus-spec.md.
