Base64 Codificatio et Decodificatio

Base64 encoding and decoding per RFC 4648, for binary inside JSON, data URIs and API authentication: encode bytes into a chorda, decode a chorda into bytes with a success flag. Small and early (December 2025); used by mensa and plist (whose <data> elements are base64).
