motus

Genus MOBILE: structura in memoria, effusa in quiete

The third kind of state, kept out of the islands on purpose: motion. Pointer capture, the pending brush stroke, pan, zoom, time of the last change, a dirty flag, in a plain struct with its own one gate (mutare_motum). The rule is 'paint per event, write in quiet': continuous input updates this struct cheaply, the screen redraws from it every frame, and the islands are touched only when motion stops (motus_quies: dirty and quies_ms elapsed since the last change), in one write by motus_effundere, which the dispensator calls at its quiet point. A stroke in progress never touches the ephemeral island at all: it leaves as one durable write on release. That is also the undo granularity: one stroke, one entry. Used by pictor and the ludus test toy.
