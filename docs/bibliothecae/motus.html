motus

Genus MOBILE: structura in memoria, effusa in quiete

The state kept out of the island on purpose: motion. Pointer capture, the pending brush stroke, pan, zoom, time of the last change, a dirty flag, in a plain struct with its own one gate (mutare_motum). The rule is 'paint per event, write in quiet': continuous input updates this struct cheaply, the screen redraws from it every frame, and the island is touched only when motion stops (motus_quies: dirty and quies_ms elapsed since the last change), in one write by motus_effundere, which the dispensator calls at its quiet point. A stroke in progress never touches the island at all: it leaves as one act of the document on release, and that is also the undo granularity, one stroke, one entry. Since 2026-10-05 it carries three more things. A gesture slot: the opaque state of an application's gesture in progress (scriba's working sheet while text is being inserted), with its own gate, its own quiet interval and the application's flush function, called in quiet and at exit so that nothing pending is lost; the flush restores the previous writer afterwards, because it can run from inside an action. The active branch: pan and zoom are flushed into the focused application's branch of the island and not into the root. And the active scope, within which focus and capture are looked up. Those two are what a host moves when focus passes from one mounted application to another. Used by the dispensator, pictor, scriba, vicus and the dismissal system.
