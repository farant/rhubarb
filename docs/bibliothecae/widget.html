widget

The first generation's widget model. A widget is a small vtable (reddere to draw, tractare_eventum to handle an event) placed in character-cell coordinates; a ContextusWidget carries the services they share (the arena, interned strings, the entity repository, the command registry) and a callback for switching modes. ManagerWidget holds up to 16 widgets in a fixed array, cycles focus, focuses on click and detects double clicks itself, reading the clock during dispatch. That last detail is what the ludus design retires: in the newer stack time comes inside the event (eventus.h) and gestures such as double clicks are derived from the event stream (derivare), so dispatch can be replayed. About fourteen views and apps still build on it (concha, arx_caeli, schirmata, the *_visus views, navigator_entitatum, libro_paginarum, sputnik_syntaxis).
