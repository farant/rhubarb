selectio

selectores CSS super arborem STML (queries)

CSS selectors over STML trees: type, #id, .class (matched against the labels attribute), attributes with all six operators ([a], =, ^=, $=, *=, ~=), the four combinators (descendant, >, +, ~) and :first-child, :last-child, :empty. Parses a selector once into a chain, then matches nodes or finds the first or all matches; stml_quaerere and stml_quaerere_omnes are querySelector and querySelectorAll in one call. Parse errors carry a position. Not to be confused with quaerere.h, which is fuzzy matching. Used by stml itself (selectio_congruit), md's extensions and oratio's tests.
