persistentia

repositorium eventuum (event sourcing storage)

Storage for event sourcing: an interface of four function pointers (write an event, read every event back for replay, sync, close) with two implementations in two files, one in memory over a xar (persistentia_memoria.c, fast, for tests) and one an append-only log file serialized with nuntium (persistentia_nuntium.c, for real use). Events concern entities: create and delete, set and remove properties, add and remove relations and notes, each with a helper constructor. entitas_repositorium replays them into current state, and concha and sputnik use the file form. It is the in-house precedent the tabularium vision cites (T9).
