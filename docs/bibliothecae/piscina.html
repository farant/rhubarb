piscina

arena memoriae: liberatio tota semel (arena, pool)

The house's arena allocator, and the memory discipline nearly every library is built on. Instead of malloc and free per object, everything belonging to one job (a document, a request, a frame) is allocated from a piscina and freed all at once by emptying it (piscina_vacare) or destroying it. Pools are dynamic (growing by adding blocks) or of fixed size; allocation either aborts on failure or, with the conari_ variants, returns NIHIL. A mark and reset (piscina_notare / piscina_reficere) gives cheap scratch space, and query functions report usage, peak, number of blocks and number of allocations, which is what actually costs. The full guide is docs/piscina.md.
