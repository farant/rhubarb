entitates_html

Referentiae characterum nominatae HTML5

HTML5's named character references: a generated table of 2,231 names (from WHATWG's entities.json, through Python's html.entities), including the 106 legacy forms without a semicolon ('amp', 'copy', 'not'), with exact lookup by binary search and a full HTML5 decoder for references: numeric with or without ';' (nothing, zero, beyond U+10FFFF and surrogates become U+FFFD; C1 controls map to Windows-1252), named by the LONGEST match, and the attribute exception for legacy forms 'for historical reasons'. Born 2026-09-15 from the html5lib oracle; used by the markdown and HTML clients. A regeneration check (-probare) tells whether the table is current.
