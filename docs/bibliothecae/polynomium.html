polynomium

Polynomia Laurentiana EXACTA super magnum

Exact Laurent polynomials in one variable, Z[t, t^-1], with Magnus coefficients; ordinary polynomials are the case with no negative exponents. One Laurent type because knot invariants need it (the Kauffman bracket in A, Jones and Alexander in t), and fourteen knotapel demos each carried a private fixed-capacity int version. Storage is dense, from the lowest exponent to the highest, so span is the cost: the parser refuses a span over 2^20, since a 30-byte text could otherwise ask for gigabytes. Exponents are bounded at |e| <= 2^30 - 1, and every operation that takes or moves an exponent returns b32 and refuses instead of overflowing; the bound was found while implementing, when adding t^(2^31 - 1) and t^(-2^31) made the coefficient count wrap to 0. Beyond arithmetic and exact division: t -> t^k and its inverse (contracting by -4 turns a normalised bracket into Jones), the normal form up to a unit +-t^k, mirror and symmetry tests, and since 2026-10-10 the derivative, gcd, square-free part and the Taylor shift p(t + c) that radices is built on. The shift is named polynomium_translatum because a glossary entry for 'taylor' lowered the English language oracle's score. Multiplication and division use internal scratch arenas ('officinae') only when a partial sum can leave s64.
