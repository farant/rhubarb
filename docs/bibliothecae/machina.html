machina

The identity of THIS machine, because measurements that do not name their machine cannot be compared: test times, screenshots and build timings all depend on it, and two runs on different machines produce noise that looks like change. The identity is a SHA-256 of a stable source (the hardware UUID, or /etc/machine-id) cut to 16 hex characters; the source itself is never emitted, so the identity can sit in shared files and git. If it cannot be determined, the answer is EMPTY, never a constant such as 'unknown', since a constant would pour every machine's measurements into one bucket while appearing to work: 'refuses, does not degrade'. A note on the name: elsewhere the house's -machina flag means 'machine-readable'. Used by mensor (August 2026).
