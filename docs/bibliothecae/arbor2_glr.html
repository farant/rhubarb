arbor2_glr

The core of an earlier generation of the house C89 parser: a generalized LR (GLR) parser that meets C's ambiguities (is foo * bar a declaration or a multiplication? a cast or a parenthesized expression?) by forking the parse and merging the branches, with piscina checkpoints to roll back. It defines that parser's AST, in which every node keeps its tokens so a file can be written back byte for byte, the LR tables (in a second file, arbor2_glr_tabula.c, which the header names for the build with an aedilis annotation), and validators for the tables. Today only its own tests and tools/glr_debug use it: silva, built on materia, is the current C parser, and this is its predecessor, kept with its tests.
