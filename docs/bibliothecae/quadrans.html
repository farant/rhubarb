Imago in cellulas terminalis (quadrantes; project-specs/

Images into terminal cells with quadrant block characters: each cell covers 2x2 pixels, split into a dark and a light group, drawn as one of 16 glyphs with a foreground and background colour (or 1x2 with the half block, exact colours at half the horizontal resolution). The algorithm was read from OpenTUI's source (its renderQuadrantBlock shader) and its deliberate differences are listed: alpha composited first, uniform blocks drawn as a space so no glyph seams show, integer arithmetic so every machine gives the same output. The default colours are each group's mean, not the extreme pair, measured at 46% of the extreme pair's error on photographs and kept as a committed aurum. Pure: no allocation, no state, returns runes and RGB rather than terminal cells, so tessera, an emulator and a window can share it. Built 2026-09-30; used by tessellatio's pixel path, tessera's effigies and saltuarius.
