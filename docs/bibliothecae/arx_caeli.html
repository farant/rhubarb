arx_caeli

The 'castle in the clouds': a spatial editor of cards. Double-click empty space to make a card, click to select (x deletes), double-click to edit its text, drag to move it without overlapping others; a card whose text starts with '>' is a folder you can enter, and #links in a card can be followed. The cards in memory are only the working set of the current screen; the entity repository holds all of them, without limit. A first-generation idea about spatial thinking (December 2025), kept as one of schirmata's panel modes.
