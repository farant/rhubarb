fabrica

The house build judge. For each artefact (a file in build/, a committed generated file, an installed binary) it says whether it was made from today's inputs, why not, and in what order to heal it. It never decides by modification time or by mere existence, only by SHA-256 seals of the inputs compared with seals recorded or obtained by regenerating. Actions are declared in aedificatio.stml files (inputs, outputs, command); a kind of artefact says how to observe it, a strategy says how freshness is known (regeneration, the binary's own provenance report, a recorded verdict, or never judged). It computes dependencies between actions from the places they read and write, orders them, groups those that could run together, heals with fabrica_sanare (judge, run, judge again), and checks that an action wrote only inside its declared footprint. It is pure, touching disk and processes only through a FabricaSutura; bin/fabrica supplies the real one, and commissio refuses a commit whose generated files are stale. It grew in slices through October 2026. Slice 2: an action can be keyed by the verified log of what its last run really read (lectiones), safe actions heal and are judged in parallel, families of actions are written once as an STML template, and results are cached by content (thesaurus, compilator). Slice 3: a gate is an action too. Its pass is a verdict keyed to what the gate read, so an unchanged set of reads means the pass stands across edits and commits, and a sampled audit re-runs reused passes to catch a record that lies. Slice 5 rolled that out and found its limit: a gate's reuse is capped by its widest honest input (the toml gate reuses its pass 78% of the time, the aedilis gate 42%, three others not at all). It also retired the old generata gate, which was a second judge of artefacts fabrica already judged. Slice 6 gave it steps: a step kind expands one declaration into members, each a synthetic verdict action run in its own area with an exact environment, and the first kind compiles, links and runs C tests itself through aedilis and compilator. Slice 7 put the root suite on it: every root test is a member, 91% of member verdicts were reused in the comparison run, each verdict carries credo's per-section results, and a test that must write outside its area declares that as a named debt. On 10-08 the library was split into seven files (fabrica_interna) and the tool into commands over a seam, and on 10-12 bin/fabrica also began to answer which gates a change owes (portae). The whole-tree photograph taken around each run turned out to be the best audit of test hygiene the house has: it caught tests deleting the residents' real commit stamp and relinking live binaries.
