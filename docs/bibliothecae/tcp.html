Bibliotheca TCP (Connexiones Rete)

TCP connections behind a platform-neutral header (implementation lib/tcp_posix.c): connect by name or address with timeout, Nagle and keepalive options; send, send-all, receive; and the server side (bind, listen, accept, the bound port when port 0 asked the system to choose). The receive contract is exact and documented: >0 bytes, 0 means the peer CLOSED and only that, TCP_ITERUM (-2) means non-blocking and nothing ready, -1 an error; send keeps 0 as 'try again', a deliberate asymmetry since 0 cannot mean EOF there. Results are structs with a named error (DNS, connect, timeout, closed, I/O, again) and a description. The worklog records the POSIX hygiene learned the hard way: SIGPIPE suppressed portably, EINTR retried, accepted sockets given the right options, and a first Linux (glibc) probe whose two findings were deliberately recorded rather than fixed. Used by hospitium, the ledger client (cliens_tabularii) and the fori tools.
