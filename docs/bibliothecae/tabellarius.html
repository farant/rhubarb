tabellarius

Cursor JSON-RPC (LEGATUS chunk A)

The JSON-RPC 2.0 carrier, knowing nothing of LSP or MCP above it. It has two layers that are kept apart on purpose. Framing: Content-Length headers (the LSP transport) or one JSON message per line (MCP over stdio), both reading from a FILE*, with a cap on body size against corrupt or hostile lengths, and refusing to write a line that contains a raw newline. Envelope: classifying a message as request, notification or response, keeping the id exactly as sent (integer or string), plus builders for responses, errors and notifications. The language server (legatus) and every MCP resident of the ledger (tabularium, fori) run on it.
