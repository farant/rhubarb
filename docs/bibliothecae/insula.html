Insulae: status in tribus generibus, porta una per genus

Where a ludus program's state lives: 'islands', STML trees reached only through this repository, in two kinds with their own write discipline. DURABILIS is what a database would hold; EPHEMERA is what survives a restore (focus, the current tool, pan and zoom). Each kind has one gate (mutare_durabile, mutare_ephemera): the mutator runs on a DUPLICATE made by writing the live tree to text and reading it back in a second arena, a canon judges the result, and only then are the two swapped, so a write is all or nothing and a tree that cannot round-trip through text cannot be written. The rehydration law: after every gated write the last honest text is kept, and insula_restituere compares the tree in memory with it; a difference is a lie (someone wrote around the gate), recorded as mendacium and repaired from the honest text. Reads are global, writes are owned: an attribute can belong to one writer (pictor's domini.stml gives zoom and pan to motus, focus to the dispensator), and a write by anyone else is refused, with the attribute, owner and offender named. An actarius hook sees every successful write. The doctrine was worked out in 32 web-component experiments in silicetum's laboratorium (Aug 2026) before this C89 port (Sept 2026).
