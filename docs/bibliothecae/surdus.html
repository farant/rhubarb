Surdi: summae radicum quadratarum, signum EXACTUM, celeriter

Sums of square roots with an exact sign, fast. A Surdus is a sum of integer coefficients times the square roots of products of up to three distinct primes, that is an element of Z[sqrt p1, sqrt p2, sqrt p3] in its natural basis, held as eight s64 values. The name is the medieval one: the Latin translators of al-Khwarizmi called an irrational root surdus, 'deaf', after the Arabic asamm, whence English surd. It is a value type with no arena and no allocation, written 2026-10-09 because knotapel demo 119 took 46 minutes, about 70% of it in extensio's big-number arithmetic, over decisions that mostly fit in machine words. The sign is decided in three tiers, each exact: zero if and only if every coefficient is zero (the basis is linearly independent over Q); then a double-precision filter that answers only when the computed value exceeds an error bound proved in the source; then recursive squaring in checked s64, writing x = a + b sqrt p and taking sign(a) sign(a^2 - p b^2) when a and b have opposite signs. What does not fit in 64 bits it refuses, and it never guesses: the caller chooses the fallback (extensio), so the hot path never allocates and refusals can be counted. The oracle is extensio in Q(cos 2 pi/120), which contains all three roots and reaches them by an unrelated algorithm; Pell units, tiny values with large coefficients, force the third tier on purpose. A planted fault that moved the stored roots by 1e-12 made the filter return a wrong sign, which is the evidence that the bound is what keeps the filter honest. Consumed by knotapel demos 120 to 123.
