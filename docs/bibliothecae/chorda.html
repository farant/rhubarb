chorda: mensura + datum, SINE NUL (string slice)

The house string: a length and a pointer, with no NUL terminator. Slicing is therefore free (chorda_sectio is arithmetic), the length is known in constant time, and embedded zeros are legal; but the C string functions (strlen, atoi, printf with %s) must never be used on its data, and the conversions here (chorda_ut_s32, _s64, _f64) exist precisely because atoi would read past the end. It covers construction, slicing, splitting and joining, comparison, search (chorda_invenire returns the matching slice, not the rest of the string as strstr does), trimming, case conversion (camel, snake, kebab, Pascal), number conversions and human-readable byte sizes; anything that allocates takes a piscina.
