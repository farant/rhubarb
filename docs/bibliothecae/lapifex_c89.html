lapifex_c89

Grammatica C89 pro Lapifex GLR

C89 as a lapifex grammar: parse an expression, a declaration, a statement or a whole translation unit with the GLR engine, producing arbor2's tree nodes. The grammar (lib/lapifex_c89_grammatica.c) grew to about 207 productions in February 2026; typedef names are told apart before parsing, by remapping identifiers the preprocessor knows as types to a NOMEN_TYPUS token, and with the full pipeline (lapifex_c89_fontem_parsare) the source goes through arbor2's expander first. Retired as the house's C parser when silva arrived. Its tests rebuilt the C table in every process (6.5 s each, the five slowest in the root suite) and were moved to archivum/ on 2026-09-02; the grammar file itself stayed in lib/ because it carries one of eight sites pinned by a ledger decree, and moving it would silently drop the pin.
