excerptum

Excerptum fontis cum signo sub tractu (forma

Draws a source excerpt the way compilers show diagnostics: a line-number margin, the source line (CR removed, control characters as spaces), then '^' under the first grapheme of the span and '~' to its end. Columns are grapheme widths from runae ('広' is two, 'e' plus a combining accent is one), and tabs in the source are copied into the marker line so the marker stays in the right column. Several spans can share one block: each source line printed once with its markers below, every line numbered, so gaps are never ambiguous. Spans out of order are refused by name rather than silently sorted. It only draws: the location comes from the caller (materia's MateriaTractus), so it knows nothing about trees and serves any source. Used by materia's diagnostics and silva's front end.
