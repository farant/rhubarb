lapifex_parsere

Motor Parsationis LR(1)

lapifex's LR(1) parse engine: drives a token stream through the ACTION/GOTO table and builds a semantic value bottom-up through a reduction callback (production index, the values of its right-hand side, an opaque context; returns the new value as an s64). Deterministic: one path, no conflicts allowed. This is the engine nuntium's schema compiler runs on, which keeps lapifex alive. February 2026.
