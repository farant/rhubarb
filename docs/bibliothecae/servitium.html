servitium

A registry of services, singleton actors found by name ('clock', 'logger'): a service is an entity tagged '#service::name', and servitium_discoperire finds them all by that tag prefix, so registration can be rebuilt from the repository alone. Used by the first-generation tests; the later house reaches services differently (the actor vision's servants, the ledger's MCP tools).
