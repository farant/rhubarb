agmen_interna

INTERNA agminis: viae scalares RELATAE.

The test-only side of agmen, not API: only lib/agmen.c, the tests and the benchmark tools/agmen_mensura.c include it. It declares the scalar reference of each public kernel: the same computation under the same contract, but with its loops marked so that clang does not vectorise them (at -O2 clang vectorised even the remainder loops until told not to). The tests compare the vectorised kernels with these element by element, bit for bit, beside congruentia's plain remainder, and the benchmark uses them as its baseline. The vectorisation gate checks this direction too, that no loop outside the marked kernels is vectorised, so the reference stays scalar. Names carry the genitive prefix agminis_ and the suffix _scalaris.
