eventus_conformitas

Tabula conformitatis fontium eventuum

A conformance table for event sources, in STML: each scene says what is injected (keys by platform virtual code with modifiers and characters, mouse actions in fenestra_musarius's words) and which Eventus stream the source MUST produce. Comparison is pure and windowless: only the kinds the scene lists are considered (stray real mouse motion is ignored), order and count must match exactly, the expected attributes must be a subset of the actual ones, and time is never compared. Actual events are written with eventus_stml and read back before comparing, so names and forms are exactly those of the replay files. The injection itself belongs to a tool (tools/conformitas), not here. The point is that the window today and the terminal later are held to one table.
