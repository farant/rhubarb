pictor_figurae

figurae pictoris (P3: tabula, titulus)

pictor's figures: how its canvas and title are drawn, registered per theme with figura. The canvas is ONE image whose identity is the content hash of the current projection, plus the pending stroke drawn as lines between the component's points, plus the cursor; pictor_imago_fons resolves that hash back to the document's bitmap when the rasterizer asks for the image by name. So the command list stays plain data (no pixel pointers), and two frames with the same document produce the same commands. Pure, like every figure.
