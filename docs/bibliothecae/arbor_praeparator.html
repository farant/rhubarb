arbor_praeparator

arbor v1's C preprocessor: #include, #define, #if and the rest, with full #if expression evaluation, run as a separate pass before parsing. Each token carries an origin chain through every macro expansion and include, so a token in the parsed output can be mapped back to the source that produced it. Macros are the hardest part of parsing real C, and tracking provenance through them was the ambition each later parser carried forward (arbor2's layered expansion, silva's expander). January 2026.
