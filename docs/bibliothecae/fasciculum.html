fasciculum

Fasciculi macOS (.app): struere, legere, conferre.

macOS application bundles (.app) as values: describe one (Info.plist as a plist value, the executable, optional resources), turn the description PURELY into a plan of files (nothing read from disk except checking that sources exist), write the plan (directories, generated files, copies, the executable bit), read an existing bundle back (refusing at the first fault, keeping unknown keys), and compare two, so a correct bundle is not rewritten. Bundle identifiers are checked against Apple's characters in one place that briar also uses. Not handled: signing, notarization, frameworks; icons belong to icones. Spec project-specs/fasciculum-spec.md (September 2026); used by briar and a tool.
