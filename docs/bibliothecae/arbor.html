arbor

The convenience front of arbor v1, the house's first C parser: one call to read a file (or a buffer) and run the whole pipeline, lex, preprocess, parse, with default options, returning a tree or an error. arbor v1 was recursive descent; it was followed by arbor2 (hand-written GLR), lapifex (generated LALR) and silva, the current parser. silva's own orientation note says why it takes the trouble to record this lineage: 'smoothed-over assumptions quietly shave the maximalist scope. That shaving is how the three previous parsers died.' Kept, not deleted (the house archives rather than deletes); its last consumers are unbuilt tools and its own tests. January 2026.
