git

lector repositorii git (LECTIO SOLA)

Reading git repositories without the git program, read-only by design: the object format has been frozen since 2005, 'among the most stable formats in computing', so a reader written correctly once stays correct forever. Loose objects (inflated by flatura, checksum verified) and pack files (.pack/.idx v2 with fanout and binary search, OFS and REF deltas applied recursively); references by full hash, HEAD, branch and tag names (loose or packed) and the ~N suffix, deliberately not ^, short hashes or ranges. SHA-256 repositories are refused clearly. Vocabulary is aligned with volumen's (massa for blob) and kept apart from the house's own hashing (git's sha is SHA-1, never called sigillum). Silex stays the house's version control; this asks git what it holds. Used by silva's differre tool (August 2026).
