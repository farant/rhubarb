fictio

valores ficti sine JSON (norma-spec par. IV)

Fake values from a seed: names, email addresses, uuids, timestamps, numbers and text within bounds, and real Latin, never lorem ipsum. Every function takes the caller's Sors, so the same seed gives the same bytes. Names are Roman (a praenomen and a gens name, or a feminine form such as Cornelia Tertia). Email addresses use only the reserved example domains of RFC 2606, so no generated address can be a real mailbox. The Latin is 48 sentences taken verbatim from Cicero's speeches against Catiline in the Project Gutenberg text, each checked to occur in the file. There is also a drawer of difficult strings, all valid UTF-8, for tests that should not be easy: the empty string, combining marks, a character outside the basic plane, right-to-left text, quotes and backslashes, an embedded NUL, whitespace only, an emoji with a modifier, a byte-order mark, a string of 2000 characters. One function draws from the drawer at random and another walks it in order. Written 2026-10-08 on a header Fran approved, for the norma line of OptChat: norma_gignere, which generates sample documents from a schema, is its consumer. Nothing in it is about JSON, though, and mock interfaces, STML fixtures and C test data can use it as well.
