libro_paginarum

A book of pages: up to 100 editor pages with navigation (next, previous, last, by number or by name), a history of 32 steps for going back, a clipboard shared between pages, and, when a repository is given, each page linked to an entity so it persists. Moving past the last page creates a new one. It tracks unsaved changes and when they were made. Inspired by page.c in Aquinas, an earlier project of Fran's (../aquinas). The editor widget the ten screens of schirmata share.
