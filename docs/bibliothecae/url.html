url

URL Percent Encoding/Decoding

Percent-encoding per RFC 3986: unreserved characters (letters, digits, - _ . ~) stay, everything else becomes %XX; decoding reverses it. Also builds a query string from key/value pairs and parses one back into parallel arrays. Small and early; used by hospitium, which decodes a path BEFORE checking it for '..' so that an encoded traversal (%2e%2e) cannot slip past.
