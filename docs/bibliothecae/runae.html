runae

Nucleus Unicode (acervus textus, stratum primum)

The Unicode core, first layer of the text stack: properties of codepoints (runae) from tables generated out of pinned Unicode data (15.1, RUNAE_VERSIO, a contract and not an ornament). It gives the width of a rune in terminal cells (0, 1 or 2, by Ghostty's rule, read from Ghostty's source), grapheme cluster boundaries (UAX #29 with the caller owning the break state, no allocation), the first grapheme or 'drawable unit' of a UTF-8 span with its width, the column width of a text, and which unit covers a given column. Two width policies: GRAPHEMATUM (Ghostty, the default) and SIMPLEX (as Terminal.app measured on 2026-09-28: emoji joined by ZWJ are not fused). Pure and total: invalid input gets a defined answer, never a crash. Units are named in every function (bytes, rune, grapheme, width), never a bare 'n'. Locale things (collation, formats) never belong here. Checked against oracles it did not write: ICU4C via dlopen agrees on all 1,114,112 codepoints (kept as a committed 'aurum' file so tests need no ICU), and GraphemeBreakTest passes 1,187 of 1,187. Used by tessera, modulus, excerptum, saltuarius. Narrative in lib/runae.phase-log.md.
