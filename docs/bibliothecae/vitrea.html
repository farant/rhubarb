vitrea

Apps whose face is a web page and whose body is C89: vitrea puts the system's WKWebView inside a window fenestra already made, serves the front end out of the binary itself (a capsula, under a capsula:// scheme that the header records was calibrated to make relative URLs and fetch behave), and carries strings both ways. Its scope is declared permanent: texture, asset origin and string transport, FOREVER; menus, dialogs and notifications will never be vitrea's. C never runs inside WebKit's callbacks: messages from JS are copied into a ring of 256 and the app drains them in its own loop (overflow is counted and announced on both sides). Navigation is allowed only to the configured origin; page errors (exceptions, rejected promises, console.error) reach stderr by default, so every app sees its page's errors without writing code. It can photograph its own contents without screen-recording permission, so nothing foreign can appear in the image. Destroy before the window. Spec project-specs/vitrea-spec-v2.md (July 2026); used by forum, villa, silex and atrium.
