processus

Bibliotheca generationis processuum (captura + terminus)

Running child processes: argv as a vector (execvp), NEVER a shell string, so quoting bugs cannot exist; stdout and stderr captured separately; a hard timeout that kills; and a result that keeps 'the process could not run' (successus false, with a named error, exec failure distinct from a real exit code 127) apart from 'it ran and said no' (a nonzero exit code is still success). Two paths over one loop body, so they cannot drift: processus_exsequi waits; processus_incipere / pulsare / metere spread the same work over ticks for programs that must not block, because the house has no threads by design and a five-second ssh would otherwise freeze a window. Output so far can be read while the child still runs. processus_transformare execs in place (same PID) for residents that renew themselves. Used by the build and ledger tools, villa, forum, manus and crusta's oracle. Born 2026-07-24; implementation lib/processus_posix.c.
