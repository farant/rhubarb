STML, XML domus: legere et scribere (markup parser)

STML, the house's markup language: a superset of XML with boolean attributes, raw-content tags (<code!>literal <>&</code>), capture operators that make a tag swallow its following or preceding siblings (<tag (>, <) tag>, <= tag =>), fragments, transclusion (<<selector>>), dotted kind names (<.species>) and anonymous closing (</>). The parser builds a DOM-style tree in a piscina with every string interned, and keeps whitespace as trivia beside the values, so writing back what was read gives the same bytes. Each node knows its source line and byte span. It offers navigation, building, mutation, cloning, labels, three readings of text (exact inner bytes, value, prose flow), a token stream for syntax colouring that tolerates half-written text, and a strict check for things that parse but leave a document silently ambiguous, such as a duplicated attribute. The single most used library after the foundations: stml_legere has 181 uses in 59 files.
