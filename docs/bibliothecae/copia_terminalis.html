Scriptura copiae (clipboard) terminalis: OSC 52

Writing to the clipboard from a terminal program: the OSC 52 sequence (ESC ] 52 ; c ; base64 ESC \\). Outgoing bytes, kept in a module of its own so that tessera, which vendors the event source, does not pull base64 into its amalgam. Reading the clipboard is paste. A terminal that does not understand OSC 52 ignores it silently, so the capability is only ever 'perhaps', never 'certain'. Eventus B3b-ii, October 2026.
