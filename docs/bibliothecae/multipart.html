multipart

Multipart Form Data Builder

Builds multipart/form-data request bodies: text fields and file parts (name, filename, content type, bytes), a generated boundary, and the matching Content-Type header, ready to hand to http. Written for uploads to web APIs (the header's example is a Whisper transcription request). Only its tests use it today.
