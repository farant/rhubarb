Destinatio: STRATEGIA una, permutabilis,

Decides which component an event goes to, as one swappable strategy that components never see. The default, destinatio_geometrica, walks the LAST composed tree innermost-first and topmost-first (painter's order is z-order), honouring clips and inverting each group's translation and scale; an active capture (a press in progress) beats geometry for pointer events; keys and the wheel, which carry no point, go to the focus. The result is the target plus its ascent to the root, so an action can be handled by an ancestor. Also: converting a screen point into a component's local space with the same arithmetic (destinatio_ad_locale), synthetic targets for derived events, and focus order (next/previous focusable, depth-first, wrapping). It reads only the logical tree, never the commands. Marked nexus purus.
