Destinatio: STRATEGIA una, permutabilis, componentibus ignota

Decides which component an event goes to, as one swappable strategy that components never see. The default, destinatio_geometrica, walks the LAST composed tree innermost-first and topmost-first (painter's order is z-order), honouring clips and inverting each group's translation and scale; an active capture (a press in progress) beats geometry for pointer events; keys, committed text and the wheel, which carry no point, go to the focus. Text was added to that list on 2026-10-05: until scriba's page no component had consumed committed text, and it had been going to the root. The result is the target plus its ascent to the root, so an action can be handled by an ancestor. Also: converting a screen point into a component's local space with the same arithmetic (destinatio_ad_locale), synthetic targets for derived events, and focus order (next/previous focusable, depth-first, wrapping). Since the scope work of 10-08 focus and capture are looked up inside the active scope, the focused pane of a host, and the strategy being swappable is what lets vicus install its own, which sends a press in an unfocused pane, and the keys that switch tabs, to the host's root. It reads only the logical tree, never the commands. Marked nexus purus.
