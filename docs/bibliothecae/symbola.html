symbola

Reads the symbol table (LC_SYMTAB) of a Mach-O binary: every local, global, external and debug symbol with its address, type, section and flags, zero-copy (names point into the binary's string table) and allocated in a piscina. Lookup by name or by exact address (both linear), iteration, and filters for functions (by heuristic, since Mach-O does not mark them) and for undefined externals, the symbols a binary needs from other libraries. It builds on macho.h, and today only its tests use it. lapifex_generare.c has a private helper with the same name as its symbolum_invenire; they are unrelated.
