componere scribae (scriba-plan S2)

scriba's view, as a Componere function for the dispensator: it reads the island and returns the component tree, writing nothing. The tree is a column laid out in cells by dispositio: a viewport that grows and clips, above a status line of fixed height; in the viewport the page, one cell in from the edge so that its frame shows, focusable, with the action pagina.clavis. What the figures need rides in the tree, as pictor's pending stroke does: the page's points are the cursor and the anchor of the selection, and its title is the mode. Scrolling has no state: when the sheet with its margin exceeds the viewport, the view centres on the cursor, clamped to the sheet's edges, a pure function of the cursor. The composition context carries a branch, so that a scriba mounted inside another application's state reads its own subtree. Written 2026-10-05 (scriba plan S2).
