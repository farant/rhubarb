sputnik_interpres

sputnik's tree-walking interpreter: values as a tagged union, scopes as a chain of hash tables, a fresh arena per execution, and errors that halt at once. Functions are not first-class (no closures escape). Scripts can call methods on arrays, entities and the entity repository (the REPO object), which is what made sputnik the first generation's scripting layer over its entity graph: <sputnik> blocks inside editor pages, coloured by coloratio and documented by the sputnik_syntaxis reference card. The ludus brainstorm names it as the available script tier. Used by tools/sputnik.
