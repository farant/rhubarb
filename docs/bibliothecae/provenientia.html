provenientia

How an installed house binary says where it came from. Run with -provenientia as its only argument, it prints four lines (format version, the artefact, the SHA-256 seal of the inputs of the action that built it, and the commit, marked dirty if the tree was) and exits. The installer writes that report into a generated file linked into the binary; bin/fabrica computes the same seal today, and equal means fresh. The report is passed in as an argument rather than looked up, so the installers, which link build objects blindly, never break on a symbol that only the generated file defines. It must be the first thing main does.
