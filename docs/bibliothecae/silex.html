silex (lapis ignarius): instrumentum distributionis -

silex ('flint'), the distribution tool, version 0: one binary that carries the sources of all the libraries, scaffolds new projects from them, and, in the vision, offers updates by hash and becomes a version control system. Version 0 does 'new': it computes a library closure by following quoted includes with aedilis's convention (include/X.h brings lib/X.c), reads sources from the tree on disk or from a capsule embedded in the binary, and writes the new project as a volumen (the truth) projected onto files, which are read back out of the volume rather than from memory so the path is tested from the start. Include scanning is textual for now, to be promoted to silva when pulled. Used by the silex tool, briar and its fabrica (August 2026).
