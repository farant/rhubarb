glyphae_ductae

characteres capsarum, quadrorum et braille ut

Characters drawn as shapes at the size of the cell and not taken from a font: box drawing (U+2500 to 257F), block elements (U+2580 to 259F) and braille (U+2800 to 28FF). The house 6x8 font has 256 slots, so these appeared as blanks in terminale: Claude Code's rounded boxes, tmux borders, btop's graphs. Ghostty draws them procedurally so that lines meet exactly across neighbouring cells, and this is a port of that code (its sprite font) with Ghostty's names kept: four arms per line character in light, heavy or double weight, dashes, arcs, diagonals, eighths and quadrants, shades as partial opacity. It is pure and allocates nothing: the result is an opacity mask, one byte per pixel, which the caller turns into drawing commands. The tests are ASCII pictures derived by hand from Ghostty's arithmetic, plus a law over the whole table: each edge of a line character is either empty or exactly a plain line's edge, at five cell sizes. Written 2026-10-07 at Fran's request after the vttest walk. A second round added 57 symbols as hand-drawn 6x8 pictures scaled by nearest neighbour, chosen by a census of the strings in Claude Code's binary and not by guess (arrows, check marks, spinner stars, key symbols); a third (10-08) added Greek letters, superscript and subscript digits and a few mathematical signs from a list of blanks Fran had seen, 118 pictures in all. terminale asks it before the font; scriba and pictor draw text through the font alone and do not see these yet.
