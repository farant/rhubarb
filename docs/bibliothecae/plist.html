plist

Tabulae proprietatum (XML property lists): legere,

Apple's XML property lists: build values of each kind (dictionaries keep their key order, so a round trip is stable and diffs are readable), set a key in place without reordering, read, write and compare. Only the plist grammar lives here: XML escaping and entities are the xml layer's job, so this builds and walks an XML tree. Binary plists, DTD validation and versions other than 1.0 are each refused by name. Spec project-specs/plist-spec.md (September 2026); written for fasciculum's Info.plist, with permissions files and LaunchAgents named as later consumers.
