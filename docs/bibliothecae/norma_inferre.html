norma_inferre

schema ex exemplis JSON inferre: ADUMBRATIO, non veritas (norma-spec-3, fasciculus B1)

A schema drafted from examples of JSON: a sketch for review, the header insists, and not the truth. Examples are added one at a time, and two inferences can be merged with the same result as adding everything to one. The draft says only what the examples show: a field is required if it was seen in every instance of its parent, objects are in the noting mode by default, a format is proposed only if every example passes it, and fields are sorted so that a shuffled corpus gives the same draft. Enumerations and bounds are given only on request, because they freeze the corpus and would carry values out of responses that may be private; otherwise no value ever leaves, except the tags of a union. Unions are found: a key present in every instance, always text, with few values, whose partition increases the number of required keys. An evidence threshold was added when the library's own first test produced a false union from an id-like field: only values seen at least twice count. The draft can carry its evidence as comments (how often a field was seen, why a candidate tag was rejected), computed by the same function that decides, so explanation and decision cannot disagree. The second half is drift: norma_comparare sets a declared schema against the observed shapes and reports, in counts and never in values, what is declared but never seen, seen but undeclared, or required but sometimes absent. Its first real report, vates's schema against captured responses, is how that schema grew, and a test now demands zero violating discrepancies against every committed specimen. Written 2026-10-09; bin/norma inferre and comparare are its tools.
