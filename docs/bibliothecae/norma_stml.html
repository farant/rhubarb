norma_stml

facies STML normae: plagulae .norma legere et scribere (norma-spec-2 §II-§III)

The file form of norma: reading and writing .norma files, an STML dialect in which named schemas can refer to one another. Judgment is in two layers. The dialect's canon, embedded through norma_canon, goes first: vocabulary, cardinality, kinds of attribute, references that resolve, unique names. The reader then checks only what a canon cannot say: exactly one type child, bounds in pairs that parse and are not inverted, cycles of references (named as a chain, a -> b -> a), generators against a registry. All faults are returned, each with line and column, and the result is all or nothing. The writer's canonical form is the STML formatter's form byte for byte, so a written file is already formatted. Names are plain and carry no '#': the spec had sketched a sigil, and canon refused it under an earlier decree about what '#' means in STML. Written 2026-10-08 on a header Fran approved. Its own final review found two silent corruptions, a newline in text folding to a space and an empty attribute value reading back as 'true'; an outside reviewer with 47 hostile inputs then found six more faults, among them a cycle between two named schemas that the emitter would have turned into C that overflows the stack. All were fixed with tests seen red first. A hook lets a caller put a comment before each node, which norma_inferre uses to write its evidence into a draft.
