Bibliotheca Reactor (Event Loop)

A single-threaded event loop over poll(): register file descriptors with callbacks for readable, writable, error or closed, add one-shot or repeating timers, then poll once (with a timeout, or none) or run until stopped. Fixed limits (1000 descriptors, 128 timers). This is the house's answer to concurrency without threads: one loop, many connections, every callback expected to return quickly. Used by hospitium; the 2026-07-20 work fixed slot reuse when a descriptor is removed and another takes its place.
