arbor2_scribere

Writes an arbor2 tree back to source by walking it and emitting every token with its trivia, so parse-then-write reproduces the file exactly; also a single-token emitter for debugging. The round-trip promise made concrete for the GLR generation, and tested on whole files (probatio_arbor2_file_roundtrip). January 2026.
