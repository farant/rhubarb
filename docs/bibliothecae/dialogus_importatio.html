dialogus_importatio

The dialog for importing an image with Atkinson dithering: only the controls (palette presets, colours on and off, breakpoints, mode), built from elementa, while the preview lives in importatio_visus. After confirmation it hands over the palette indices, size and title of the dithered image, which the gallery stores as an entity. From January 2026, with the gallery work.
