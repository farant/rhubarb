tessellatio

Mandata in cellulas terminalis: via cellularum

Mandata into terminal cells: the second backend for the drawing list, so the same ludus UI can render in a terminal (tessera). Pure: the caller supplies the output grid, there is no state and no dependency on tessera. A cell holds a text unit (a whole grapheme, wide units taking two cells), box-drawing junction bits, or nothing. The rules follow the pixel rasterizer exactly (origin + local × scale, clip intersected with the parent's), then decide per primitive: lines floor into their cell, filled rectangles and text snap to the nearest cell edge, axis-aligned lines OR their junctions into ┼ ├ ┬, outlined rectangles become box borders. What cells cannot express (images, polygons, diagonal lines) takes a pixel path: rasterized by delineare_mandata, scaled, and turned into quadrant block characters underneath the cell layer. Cell geometry comes from a Modulus (lib/modulus.c). Built 2026-10-01 (plan project-specs/tessellatio-plan.md, narrative lib/tessellatio.phase-log.md); used by tessera's musivum tool.
