pagina

One page of the first-generation text editor: a fixed character grid (tabula_characterum, 68 x 56 by default) edited with vim keys (vim), coloured by coloratio, with a blinking cursor, rendered into the window with a margin. Text in the page can hold clickable regions (a $command, a #link, a block) that the page finds and reports. The page handles only display and input; editing logic is delegated to vim. Each page has an identifier ('page:5') and can share a clipboard and keep its own undo stack. From the first weeks (2025-11-18); libro_paginarum holds many of them.
