actio

Registrum actionum NOMINATARUM

The registry of named actions. Markup NAMES its actions (actio="salvare" on a component), it never computes them, and the program registers one handler per intention; the phase comes from the event's kind. A handler gets the state repository, the motus, the target with its ascent, the matching node (possibly an ancestor of the target), the event and its context, and returns whether it consumed the event, which stops the ascent. Handlers perform no I/O: effects are returned as data. Resolution runs both ways: a name used in the tree with no handler is an error (actio_non_registratae), a handler no component names is a warning (actio_non_relatae). Duplicate and empty names are refused. Used by pictor_actiones and the test toy; marked nexus purus.
