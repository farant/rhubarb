fenestra_tempus

The platform clock, split out of fenestra.h on 2026-10-01: ticks, tick frequency, milliseconds, sleep, implemented with mach and POSIX calls and no Cocoa. Before the split, lib/tempus.c pulled all of fenestra_macos.m into its link just to read the clock, through an object annotation that the build did not follow, so the window's newer dependencies were missing there. fenestra_tempus_ms is the one place event time is read (ludus: time is data in the event). fenestra.h includes it, so callers see no change.
