cursus

The message bus of the first generation: send a message to an entity id and it is queued, not handled at once; cursus_processare then delivers up to a given number of messages, looking up each recipient's handler by (entity genus, message kind) in tractator. Mailboxes are created only for entities that receive something. A bounded processing step per call keeps one busy actor from starving the rest, the same instinct as the reactor's quick callbacks. Used by its tests, the actor integration test and tempestivum's tests.
