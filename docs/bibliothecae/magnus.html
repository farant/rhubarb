magnus

Integri magni EXACTI (sine limite)

Exact integers of any size, with no silent overflow. Born 2026-10-05 as the first of the house's exact-math foundations, after a read-through of the knotapel demos found whole chapters of results (demos 110 to 112) resting on silent 64-bit overflow in a private rational type. A Magnus is an immutable value, like chorda: every operation returns a new one, memory comes from a piscina, and a result may share limbs with its arguments. A number that fits s64 always lives inside the struct and costs no allocation; anything larger is 32-bit limbs, and the form is canonical, one representation per number. Division is Euclidean (0 <= remainder < |divisor|): C89 leaves the sign of a negative remainder to the implementation, and the house defines it. Multi-limb division is Knuth's algorithm D. No floating point anywhere, so the result is the same on every machine and at every optimisation level. The gcd gives Bezout witnesses on request, a certificate that can be checked without this library. Its worklog is where the review step for math libraries began: an independent reviewer found that replacing magnus_aequalis by 'return true' passed the whole suite, because every property used it as the judge. magnus_apex_alternarum reports the scratch memory of the last large gcd, a deterministic cost counter that tests assert.
