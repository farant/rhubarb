tabula_characterum

craticula characterum 2D (text grid)

A 2D character grid for a text editor that behaves like paper: a fixed size (68 x 56 by default), typing paints into cells, and inserting before content pushes it right up to a 'barrier' (the last whitespace before content), wrapping with indentation kept when a line overflows. Tabs take two cells (a tab plus a continuation marker) so one backspace deletes them. No cursor and no UI state: pure grid operations (push right, pull left, insert and delete lines and characters, find connected content), with helpers to build a grid from a string and assert on it in tests. The model under pagina and vim in the first-generation editor (Nov 2025).
