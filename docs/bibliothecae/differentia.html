differentia serierum et linearum (diff)

Diff. The core compares two sequences of POINTERS, by identity: the caller interns its elements, so one core serves lines, silva tokens, words or STML nodes alike. The result is runs (same, deleted, added), with an invariant tests check: same+deleted partition A, same+added partition B, nothing hidden, nothing counted twice; deletions come before additions within a change (the GNU convention). Myers' O(ND) algorithm gives a minimal edit script. Per Eskil's advice the API is frozen and the body replaceable: patience or histogram diff could go in later under the same API. A pragmatic cap: past 2048 steps the script becomes 'delete all, add all', keeping the invariant but not minimality, since memory grows quadratically and such a diff is unreadable anyway. differentia_linearum is the wrapper for text; the unified ---/+++/@@ output is a presentation, kept apart from the core. Used by silex and silva's differre tools.
