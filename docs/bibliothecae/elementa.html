elementa

Immediate-mode controls for the first generation's dialogs: a slider, a button, a checkbox, a text field and a 2x8 grid for picking one of the 16 Aquinas colours. Each call draws the control and returns a small result struct with what happened this frame (clicked, changed, the new value), so there is no retained widget state to keep in sync. Written as part of the gallery's second phase (January 2026); used by the image import dialog.
