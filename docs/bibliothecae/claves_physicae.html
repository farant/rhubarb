Codices clavium platformarum -> EventusCodex

Pure tables from a platform's virtual key codes to the vocabulary's physical key codes (W3C 'code' values): today macOS's kVK codes, the kitty terminal protocol in eventus phase B. Position, not layout: macOS key 0 is 'KeyA' whether the keyboard is QWERTY, AZERTY or Dvorak. Unknown codes map to EVENTUS_CODEX_IGNOTUS. No Cocoa: fenestra_macos.m calls it, and tests use it without a window. 2026-10-01.
