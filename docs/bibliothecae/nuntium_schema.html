nuntium_schema

Lingua Schematis Nuntii

The schema language for nuntium, the house's protobuf-like message format. It parses declarations such as nuntium Persona { textus identificator = 1; varint aetas = 2; }, typed fields with tag numbers, into a small AST, and generates C from them, a header and a body (in a second file, nuntium_schema_generare.c). Field types: text, varint, svarint, fixed 32 and 64, bytes, f32, f64. The command-line generator instrumenta/nuntium_schema_generare.c is its user.
