norma_canon

textus norma.canon infixus (norma-spec-2; regula R1

The text of norma.canon, the schema of the .norma dialect, embedded in the binary so that the reader needs no file. One function returns a copy. The body, lib/norma_canon.c, is generated by tools/norma_canon_infigere.sh and never edited by hand; a fabrica action judges it, and a test asserts that the embedded bytes equal the file on disk, so a canon edited without regeneration is red at once. capsula, the house's usual embedder, was not used: it writes its header beside its configuration, outside include/, and its runtime pulls in three libraries for one file of 6.5 KB. Written 2026-10-08; norma_stml is its only consumer, and organum_canon later copied the pattern.
