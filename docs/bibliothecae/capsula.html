capsula

File Embedding Library (Go embed-style)

Embedding files in a binary, in the manner of Go's embed: a build tool (capsula_generare) reads a configuration, compresses the files and generates C data; at run time this library opens the embedded capsule and reads files by path, with an iterator over them all. How vitrea apps carry their whole front end, speculum carries its sources and silex carries the library corpus inside a single executable. From December 2025; used by forum, villa, briar, atrium, silex and speculum.
