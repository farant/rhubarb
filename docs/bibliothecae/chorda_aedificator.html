chorda_aedificator

chordas accumulare (string builder)

The string builder, for text whose final size isn't known: append characters, chordae, C strings, integers, floats, hex and runs of a repeated character to a buffer that grows in a piscina, then take the result as a chorda with chorda_aedificator_finire. It was made for generating structured text (JSON, XML, INI, logs), so it carries JSON escaping and an indentation level (push and pop) for pretty printing; truncare allows optimistic writing with rollback, and reset reuses the buffer. json's writer is built on it.
