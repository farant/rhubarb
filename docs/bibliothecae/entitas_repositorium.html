entitas_repositorium

The repository interface over entities: a struct of function pointers (read by id, related entities, query by tag or tag prefix, by genus or genus prefix, by text; roots; back-references; create, scaffold, delete, set and delete properties and relations) with an opaque datum, so consumers depend on the interface, not on an implementation. 'Scaffold' is idempotent: a deterministic UUIDv5 from genus and title gives the same entity every time. The single implementation (lib/entitas_repositorium_impl.c) is event-sourced over persistentia, the same code whether events live in memory or in a file. Used across the first-generation views, the sputnik interpreter, tempestivum and the event inspector tool.
