librarium_lector

"Lector Librorum"

Loads and reads one book's text for the library viewer: loading from a file, pagination by page (paginarium) or by sentence (sententia_paginarium), cached until the size changes, and reading progress saved per book. Kept separate from the catalogue view, which only lists and chooses (December 2025).
