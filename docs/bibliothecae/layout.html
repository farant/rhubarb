layout

Builds a screen from an STML description: a layout document names its widgets, their kinds and their places, and layout creates them, registers them with a ManagerWidget and lets the program find them again by id. Known kinds include pagina, navigator and libro, and a registry of widget factories lets other libraries add their own. Part of the first GUI generation (2025-11, the arx_caeli / schirmata era), built on widget.h and using character-cell coordinates; its one caller outside tests is schirmata. The newer ludus/manus stack does not build on it.
