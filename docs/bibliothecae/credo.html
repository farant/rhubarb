probationes: assertiones CREDO_* (unit tests)

The test framework: CREDO_* assertions (credo, 'I believe') that record each check with its expression, both values, file and line, then report a summary. Typed comparisons for pointers, signed and unsigned integers of each width, floats within a tolerance, chorda (equal, contains, starts, ends, empty) and literals. Two details carry history: a test that asserted NOTHING does not pass ('NIHIL PROBATUM', 2026-09-02), and CREDO_CULPA records a declared failure for an early exit, so the summary and the exit code always agree. Process assertions (CREDO_NON_RUIT 'does not crash', CREDO_NON_PENDET 'does not hang', CREDO_RUIT_CUM 'dies with this signal') run the expression in a FORKED child; they are statement macros so the expression is evaluated only in the child, and they never catch SIGSEGV in-process, since returning from a fault handler is undefined. Used by every probatio in the house (over 400 files); probationes/probatio_piscina.c is the reference usage.
