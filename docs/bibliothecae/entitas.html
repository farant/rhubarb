entitas

The first generation's data model: an entity is an id (UUIDv7), a genus (its kind, e.g. 'Page'), typed properties, directed relations to other entities (each relation with an id of its own), and tags ('#root', '#service::clock'). A property keeps its original string and a semantic type ('Currency::USD') and can be parsed once into s32, s64, f64, a boolean or a timestamp, cached; binary properties are compressed with flatura automatically. All strings are interned. A relation can be added with a given id, for replaying events. The vocabulary of the old GUI: pages, folders, images and services were all entities. From November 2025.
