tabula_dispersa

tabula friationis (hash table, map)

The house hash map: open addressing over a flat array of slots, keyed by chorda, with void* values, allocated in a piscina. Insert (overwriting an existing key), find, contains, delete with tombstones, clear without freeing (arena-friendly), iterate, plus load-factor and collision statistics for diagnosis; it hashes with friatio's FNV-1a by default and compares keys by content. One caveat: it silently refuses zero-length keys (ledger note …6KEQPR), which is why internamentum, and json above it, treat the empty string specially. This is the library to use when a JSON object is being used as a map (lapide feature request 025).
