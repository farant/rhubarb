arbor2_lapifex_adaptator

Pons inter Arbor2 Lexer et Lapifex Parser

The bridge between arbor2's lexer and lapifex's generated parsers: converts a stream of arbor2 tokens into lapifex symbols, mapping each token kind to the terminal of a grammar written in STML, and carries the original token as the symbol's semantic value (a pointer stored in an integer and cast back). The point where the hand-written GLR generation handed over to the generated one (February 2026).
