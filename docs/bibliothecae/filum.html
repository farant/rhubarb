filum

fila legere et scribere (file I/O)

Files: read a whole file into a chorda, line readers, writers (create or append), copy, move, delete, directories (create, create if needed, create with parents like mkdir -p, create with a mode and enforce it), chmod, status. Each newer function says WHY it exists: copy does not keep the mode, so an executable copied into a .app bundle silently stopped being executable (hence filum_modum_ponere); a private directory must be 0700 even if something else created it 0755 first; filum_arborem_delere uses lstat so a symlink to a directory is removed as a link instead of walked into, and refuses the system root by identity, not by spelling ('//' and '/tmp/..' too). An exclusive lock (flock) for read-check-append sequences, held by the kernel and released when the process dies, so there are no stale locks (lapide FR-020). The most used I/O library in the house (filum_legere_totum: 229 calls in 92 files).
