vigilia processus residentis: binarium currens

Watching whether a resident process is still running what it should: two watches with one contract. The disk watch notices that the binary on disk has changed under the running process (a hash confirms it, so an identical rebuild renews quietly), and the sources watch notices that any source in the launcher's manifest is newer than the running binary. The manifest is written by the launcher itself, the true list of what it would compile, so watcher and builder cannot disagree. Nanosecond modification times close the same-second window on APFS. The state is sticky (once stale, never back), and an incomplete configuration gives a quiet watcher that never blocks and never lies. Generalized on 2026-07-16 from two hand-rolled versions; used by the ledger's resident, legatus and silva's examen, and the source of the 'CAUTIO VIGILIAE' warnings.
