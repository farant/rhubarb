Bibliotheca URI Parsing (RFC 3986)

URIs per RFC 3986: parse into scheme, userinfo, host (including bracketed IPv6), port, path, query and fragment; build one back; normalize the path (dot segments, through via.h); resolve a relative reference against a base; default ports for http, https and ftp; compare. Percent-encoding is left to url.h. Only its tests call it today.
