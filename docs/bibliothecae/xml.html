xml

A plain XML reader and writer: a DOM-style tree of elements, text and comments, every string interned, everything in a piscina, with error line and column. No namespaces, DTDs or CDATA, and a document type declaration with an internal subset is refused. STML is the house format; this exists to read other people's XML, and plist (macOS property lists) is its one user.
