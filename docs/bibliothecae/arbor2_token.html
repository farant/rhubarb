arbor2_token

arbor2's token, the unit the second-generation parser was built around: every token carries a provenance chain back through macro expansion to the source, always allocated so no code checks for NULL, with the macro that produced it and its expansion layer, and, for tokens made by ## pasting, links to BOTH tokens that were pasted. arbor2_token_radix walks back to the original source token. Where arbor v1 tracked origins as a side feature, arbor2 made provenance the definition of a token (January 2026).
