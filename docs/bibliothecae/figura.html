Figurae: registrum (partes, thema) -> deponere, et

The other tree's other half: a registry from (partes, thema) to a drawing function, and pingere, which walks a componens tree and emits Mandata, opening one group per component (its bounds, clip, transform and id) and calling the registered figure before the children. Kinds are data, not types: there is no function on the component and no struct per kind, so a new look is a new registration, and a theme is a column of the registry. pingere and every figure are pure (annotated <purus/>): they write nothing but commands, which is why a figure can be tested once per theme instead of once per widget. figura_finium, an outline in the border colour, is the fallback for kinds nobody has drawn yet. Used by ludus_fenestra, pictor's figures, and tessera's musivum tool, which renders the same tree in a terminal.
