rete

inspectio interfacierum reticuli localis

Which local addresses this machine has, to answer 'at what address can my phone find me?': a vitrea server can bind 0.0.0.0, but the URL put in a QR code needs a concrete address. There is no single local address (home wifi and a phone hotspot on en0, VPN tunnels, bridges, loopback, and 169.254 addresses that exist but reach nothing when DHCP failed), so the library does not guess: it returns every live, non-loopback, non-link-local IPv4 address with its interface name, in the system's order, and the caller or the person chooses. Implementation lib/rete_posix.c (getifaddrs); used by forum for phone pairing (August 2026).
