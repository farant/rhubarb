scrinium

scrinium (arca documentorum): involucrum Latinum

The house's Latin wrapper over the one vendored database, SQLite (vendor/sqlite3.c, compiled loosely in its own object, treated like libc): open (or ':memoria:'), execute, prepared statements with typed binding and columns copied into the caller's arena, transactions, migrations that are append-only and numbered with no way down (history immutable), and ULIDs for row identity, kept distinct from content identity, which is sigillum's job. Build flags were decided when SQLite was vendored: FTS5 in, no threads (one writer, the house rule), WAL with a busy timeout so readers can run alongside. Used by the ledger's journal (gesta), volumen and fabrica (July 2026).
