delineare_mandata

Mandata -> TabulaPixelorum (rasterizator CPU)

The CPU rasterizer for Mandata, the house's drawing command list: walks the commands and paints them into a TabulaPixelorum, applying group transforms and clips, resolving colour names through thema and images by name through an ImagoFons (so the list stays plain data, with no pixel pointers in it). A variant takes a filter, a bare-tabula entry point serves tests, and a Modulus/mensor hook lets tessellatio measure before it draws. The split it embodies is retained mode over immediate mode: a program builds a list of what to draw, and this one function turns the list into pixels, so the same list could later go to another backend (the GPU, PDF, a test that compares lists rather than pixels). Used today by ludus_fenestra, which is the glue between a ludus program and a real window.
