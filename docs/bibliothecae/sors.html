sors

Numeri pseudo-fortuiti SEMINABILES et deterministici

Seedable, deterministic random numbers: the same seed gives the same sequence on every machine, compiler and version, because the generators are integer-only (PCG32 for the stream, SplitMix64 to expand the seed). That makes replays, procedural artefacts and fuzzing reproducible. A Sors is a 16-byte value, with no arena and no global state, so it can be copied and stored inside an event. sors_derivare makes a child stream from a parent and a key WITHOUT changing the parent, so child k is the same however many others were derived before it. Unbiased ranges (Lemire), floats from 53 or 24 bits, a probability check, Fisher-Yates shuffle. Deliberately distinct from moneta, which reads /dev/urandom for identities: secure, but not seedable. Born 2026-09-23; the house migrated to it the next day (knotapel keeps its own generators by design). Keeps the classic ANSI LCG under a 'legacy' name so old generated test cases stay the same.
