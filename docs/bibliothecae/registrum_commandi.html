registrum_commandi

The first editor's command registry: commands such as $date are typed into the text and executed by name, each with a context giving the page, the grid position where the command ends, an arena and data registered with it. 'Commands are fundamental, not ad-hoc handlers': a registry makes them discoverable. Coloratio can colour only registered commands. Used by concha and the views that add their own commands.
