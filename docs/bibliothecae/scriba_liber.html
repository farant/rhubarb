liber paginarum scribae (vicus-latera S2b)

The book of pages: named pages in one volumen, written 2026-10-08 so that vicus could show the same page in more than one pane. An index record lists the names in navigation order, and each page's text is a scriba_documentum in its own namespace. The rule that shapes it is one document object per name per book: a page is opened or created on first ask and the same object is handed out ever after, because two instances of one history in one volume would write diverging logs. A new page takes the next unused number as its name; scriba_liber_paginam_condere finds or creates a page by a given name, which is what a '$scriba(name)' command inside a page calls. There is no limit on the number of pages. The legacy libro_paginarum, which stopped at 100, is left untouched. Used by scriba_actiones for navigation and links, and by vicus.
