specula

specula plagulae: fossa quae legenda fit cum plagula mutatur (scripta, extensa, deleta, renominata, creata) - ansa (reactor, fenestra) in ea exspectat et plagulam solum tunc legit, numquam per pulsum (vicus quies T6c: …

Watches one file and gives a loop a descriptor that becomes readable when the file changes: written, extended, deleted, renamed, or created after being absent. The loop waits on it (in a reactor or the window's run loop) and reads the file only then, never every pulse. specula_exhaurire empties the pending notices and says whether the file changed; it must be called on every wake, or the loop spins. If the file is absent it watches the parent directory until the file appears. After a delete or rename (log rotation) it reopens the same path. It never reads the file itself. On macOS and iOS it uses kqueue on an O_EVTONLY descriptor, which doesn't keep a volume from unmounting. On Linux and Android inotify isn't written yet, so specula_creare returns NIHIL and the caller goes back to frequent pulses. Written 2026-10-26 for vicus quies, where it replaced reading the notifications log on every pulse.
