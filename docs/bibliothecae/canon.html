canon

Schema checking for STML, itself written in STML: a .canon file describes a dialect, and canones.registrum maps file extensions or root elements to canons. It enforces a closed vocabulary, the number of children per element, typed attribute values (name, number, true/false, date, choice, kebab name, identity and reference), required attributes, where text may appear, unique names, keys and citations within a document, and value bounds, and it can judge a document as written, expanded, or fully distributed. Deliberately not: resolving references across files, validating against a computed model, or any expression language, since that road turns a schema into a programming language (XSD is the witness). A document may carry its own canon as its first child, but it can only add to the registry's canon, never weaken it. Used in 25 files, from silex and insula to the canon and natura checkers.
