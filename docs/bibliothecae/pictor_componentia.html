pictor_componentia

componere pictoris (P3: prospectus, tabula,

pictor's view, as a Componere function for the dispensator: reads the islands and motus and returns the component tree (toolbar, canvas, status line) into the arena it is given, writing nothing. Kinds are data, so there is no type per component; the canvas's action name is computed from state (the current tool 'penicillus' gives 'penicillus.ictus'), which means handlers never branch on the tool. The pending stroke's points are copied into the canvas component so that painting reads only the tree. The concrete case of 'the component is a pure projection of its islands'.
