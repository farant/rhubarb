derivare

Derivatio eventuum PURA ex fluxu crudo

Turns the raw input stream into the derived one, purely: double clicks from the events' own times (never the clock), and drags, once a press moves beyond a distance threshold: TRACTUS_INCIPIT at the press origin, TRACTUS while moving, TRACTUS_FINIT on release (a drag does not count as the first click of a double click). Each raw event is appended to the output followed by whatever it derives, so downstream code sees one stream. Hover and focus are derived later, in the dispensator, because they need to know which component is under the pointer. Independent of how targeting is done. Marked <aedilis nexus="purus"/>. Replaces the old ManagerWidget's clock-reading double-click detection (see widget).
