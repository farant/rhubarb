nuntium

serializatio binaria (protobuf-style encoding)

The house's binary serialization in the style of protobuf: fields as a tag and a wire type (varint, fixed 32 and 64 bits, length-delimited), varints of seven bits per byte, zigzag encoding for signed values. A writer grows a buffer in a piscina; a reader walks fields, skips unknown ones and reads strings and nested messages zero-copy, pointing into the original bytes. nuntium_schema generates code for it from declared schemas; persistentia's event log and oratio's vocabulary use it directly.
