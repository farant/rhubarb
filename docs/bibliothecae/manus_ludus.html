manus_ludus

manus IN PROCESSU super dispensatorem

A test hand that drives a ludus program in-process: the same verbs as the out-of-process manus (press, key, exists, focus) but synchronous, so there is no waiting and no flakiness. It finds components by selectors over the LOGICAL tree ('#id', '[partes=x]', '[actio=x]', '[titulus=x]'), maps a component's local point to the screen by exactly inverting the targeting transform, and presses, moves, drags and types through the real dispensator. Time advances only when the test says so (manus_ludus_exspectare) or by a fixed step per event; there is no clock. It also replays a recorded session: CRUDA sends events as recorded, SEMANTICA re-aims each pointer event at the component it originally reached in today's tree, and both report divergences (a recorded position that would now hit something else), which is how a layout change shows up in an old recording. A malformed selector names its cause. CREDO_MANUS_LUDUS_* assertions for tests.
