html_lexema

A total lexer for HTML, the tractable half of an HTML5 tokenizer, under the same contract as css_lexema (total, byte-faithful, byte positions, trivia as tokens; anomalies get a PRAVUM kind rather than an error). Unlike CSS it carries state across tokens: after '<div' it is inside a tag (attributes), after '<script>' it is in raw mode until '</script'. Tag case is noted, not normalized, and character references are not decoded here (that is entitates_html's job, in the tree). Used by the html client on materia (html_arbor), md's oracle tests and briar. August 2026.
