coloratio

Despite the name, syntax colouring, not colour science: computes a colour index for every cell of a character grid (normal text, $commands, <tags>, keywords, strings, numbers, comments, operators, properties, attributes, #links, type annotations), which the page then draws through the theme. Two passes so that multi-line blocks (a <sputnik> script inside the text, a string, a comment) are coloured with their context. Rules are switched on by flags, and with a command registry only real commands are coloured. Pure computation, testable without the page.
