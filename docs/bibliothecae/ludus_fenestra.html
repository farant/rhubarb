ludus_fenestra

glutinum fenestrae: eventus -> dispensator,

The glue between a ludus program and a real window, and on purpose the only place ludus touches the clock (fenestra_tempus_ms) or sees a window. Events go into the dispensator; each frame is a pulse, then pingere of the last tree into a per-frame arena, then delineare_mandata into the window's pixel table, then present. It measures each frame (composition, painting, rasterizing, worst frame) and prints the measurements, because the brainstorm left one optimisation conditional on them: if rasterizing dominates, rasterize frame N while frame N+1 is dispatched. ludus_fenestra_currere is the whole run loop, ending on close or after a frame count (for smoke tests). Used by pictor. Small by design: everything that can be pure lives below it.
