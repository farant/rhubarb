I. Foundation

25 libraries, 25 described

What every other library stands on. latina is the dialect itself; piscina (arenas), chorda (strings with a length, never NUL-terminated), xar (growable arrays), tabula_dispersa (hash tables) and internamentum (interned strings) are the data structures nearly every function takes or returns; credo is the test framework every probatio uses. Around them, the plain services a C89 program has to write for itself: files, paths and directory walks, child processes without a shell, hashing (friatio to disperse, sigillum's SHA-256 to identify), identifiers (moneta, uuid), seedable random numbers (sors), DEFLATE (flatura), Roman numerals for latina's own number block. Most were written in the first weeks (October-November 2025) and have been hardened since; their headers are where the 'why it exists' paragraphs are densest.

II. Text

15 libraries, 15 described

Text from bytes up. utf8 decodes and encodes; runae is the Unicode core (cell widths, grapheme boundaries) checked against ICU and the Unicode consortium's own test file. Above it sit two generations: the first, written for the Gutenberg reader in December 2025 (paginarium, sententia_fissio, sententia_paginarium: verse or prose per paragraph, sentences that survive 'Mr.' and '$3.50'), and the newer, pure and oracle-checked tools of 2026: excerptum (compiler-style source excerpts), differentia (diff), similitudo and quaerere (fuzzy matching), sententiae (books of numbered claims with anchors that never lie). paginatio and capitula read page numbers and chapter indexes; partitio groups rows for oratio.

III. STML and data formats

15 libraries, 15 described

STML is the house's own XML, and the format most of the house's records are written in: configuration, build rules, schemas, transcripts of events and drawings. stml reads and writes it losslessly, byte for byte; stml_macros expands templates as pure projections; canon checks a document against a schema itself written in STML; selectio queries it with CSS selectors; stml_html renders it. Beside it, the formats the house exchanges with others: json, a plain xml, Apple's plists, HTML's named entities, and nuntium, a binary encoding in the style of protocol buffers with its own schema language. natura loads the house's semantic library (taxonomies, dictionaries) from STML; the two *_lectio headers are generated readers for canon-described files.

IV. Parsers: the C89 lineage

25 libraries, 25 described

The house parses its own C, and these headers are the generations of that effort: arbor v1 (recursive descent, January 2026), arbor2 (hand-written GLR, to follow several readings where macros and typedefs make C ambiguous), lapifex (a generator of LALR and GLR parsers from grammars), and then silva, the current parser, which lives in its own folder on the materia substrate and is not listed here. silva's orientation note says why the lineage is kept in view: 'smoothed-over assumptions quietly shave the maximalist scope. That shaving is how the three previous parsers died.' The house archives rather than deletes, and one generation turned out not to be retired at all: lapifex is still the engine under nuntium's schema compiler, superseded as a C parser while load-bearing as a parser generator. The group also holds sputnik, the first generation's small scripting language (lexer, Pratt parser, tree-walking interpreter), and the lexers for CSS, HTML and JavaScript.

VI. Records and storage

6 libraries, 6 described

Where things are kept. persistentia stores events (event sourcing: append, then replay) behind a small interface with memory and file implementations; scrinium is the Latin wrapper over SQLite, the one vendored database, with append-only migrations; volumen builds on it to keep a whole document in one file whose truth is an event log, with content-addressed blobs; mensa stores a vitrea app's desk of cards that way. cliens_tabularii and tabellarius are how programs talk to the ledger's resident daemon (JSON-RPC over a socket). The common thread is the projection rule: the log is the truth, everything else can be rebuilt from it.

VII. Network

11 libraries, 11 described

The network stack, written in the summer of 2026. tcp and tls (Security.framework today, BearSSL named for elsewhere) share one exact receive contract, where 0 means closed and nothing else; http speaks HTTP/1.1 both ways; uri and url parse and encode; reactor is a single-threaded poll loop and router a pure matcher. hospitium assembles them into the house's HTTP server: one thread, an arena per request, visible refusals. The stack's worklogs hold its best lessons, chiefly the TLS truncation of September 2026 that a test asserting only 'something arrived' could not see.

IX. Window, input and drawing

22 libraries, 22 described

The layer between the operating system and anything visual or interactive. fenestra opens native windows and injects real input for tests; eventus is the vocabulary of input with time inside each event, split from the window so that pure code links no Cocoa, with its queue, its conformance tables and its STML transcripts. Since October 2026 the terminal is a second source of the same vocabulary: terminalis (raw mode), series_terminalis (the byte-stream lexer, after Williams and Ghostty), interpres_terminalis (honest decoding, legacy and kitty), rivus_terminalis (the pure source) and codificator_terminalis (the inverse, so sessions replay through a terminal too). tabula_pixelorum is a bare pixel buffer; delineare draws on it QuickDraw-style; delineare_mandata rasterizes a command list; thema holds the 16-colour palette; fons and fons_6x8 the bitmap font. modulus and tessellatio carry the same drawing into terminal cells. manus is the out-of-process test hand for live applications.

The UI architecture of September 2026, worked out first in 32 web experiments and then ported to C89. Two trees never fused: componens says what each thing is, figura says how it is drawn, and drawing produces mandata, a plain command list, never pixels. One loop (dispensator: derive, target, act, recompose) runs and is tested with no window; ludus_fenestra is the thin shell that has one. State lives in insula's islands behind one gate per kind, with motion (motus) written only in quiet; manus_ludus drives and replays it all in-process. pictor, the raster editor, is the first application built on it, and its four libraries are here.

XII. The first generation

34 libraries, 34 described

The house's first application layer (November 2025 to January 2026), most of it still running through concha in the Combinado demo. Its model is an entity graph (entitas, an event-sourced repository) with an actor layer on top (messages, a bus, handlers by kind, services, timers); its interface is character-cell widgets with a manager that reads the clock, screens switched like tmux, a paper-like text editor with vim keys and syntax colouring, and a panel of viewers for cards, themes, fonts, the Bible, the library, the calendar and images. Much of what came later answers something learned here: ludus replaces the widget manager (its brainstorm says so by name), and the actor vision of October 2026 restates the actors with a supervision tree.
