Bibliotheca Router (HTTP Route Matching)

Pure route matching for HTTP: register a path per method ('/users' exactly, or '/users/:id' with up to 16 parameters), then match a method and path into the registered datum plus extracted parameters. When the path matches but the method does not, the result says so and gives the allowed methods as a bit mask, so the server can answer 405 with an Allow header instead of a wrong 404. The datum is an opaque pointer; because ISO C under -pedantic forbids putting a function pointer in a void*, the consumer registers a small 'capsule' struct holding its handler (the pattern hospitium uses). Rewritten as a pure matcher in July 2026 for hospitium.
