manus

The test hand for live vitrea apps, built on imperium's channel: press, type, scroll, move, keys, screenshots, read text, count, focus, resize, all by CSS selector, and CREDO_MANUS_* assertions. Its central decision: NO sleep function, on purpose ('if a sleep can be written conveniently, someone will use it'), because timing is what kills UI test suites. Waiting happens inside the page, as a promise that resolves when the condition holds or a deadline passes, so a transient state cannot slip between two polls, and the hand keeps a slightly longer outer deadline in case the page itself is hung. Assertions wait until true. Selectors see only VISIBLE elements, because a hidden element is still in the DOM: laboratorium experiment 0001's test asserted that a form had gone while it was only hidden. After the first failure the hand goes quiet, so one real cause shows instead of ten consequences. Used by tools/manus_instrumentum (August 2026).
