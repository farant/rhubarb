moneta

Cusio identitatum (ULID, nanoid)

The mint for identities, one for the whole repository so that the ledger and code annotations draw ids from the same space. ULIDs (time first, so they sort by creation; monotonic within a millisecond), a non-monotonic variant whose short prefixes still differ, nanoids (21 characters of a 64-sign alphabet), nanoids for file names (12 upper-case characters, since macOS file names ignore case), and nanoids of any alphabet, drawn uniformly by masking and rejection rather than by modulo. Its rule about randomness: a ULID may fall back to time mixing, because it needs uniqueness; secrets and nanoids never fall back, because a predictable fallback would look like success. The ledger mints its ids here.
