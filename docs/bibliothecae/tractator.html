tractator

The handler registry for actor messages: (entity genus, message kind) to a function, with a fallback per genus for kinds it does not know. A handler receives a context with the entity, the message, the repository, the bus (to send more) and the arena. Behaviour belongs to the KIND of entity, not the instance, the same move ludus later makes with figura (kind and theme to a drawing function) and actio (a name to a handler).
