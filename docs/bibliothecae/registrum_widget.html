registrum_widget

Widget factories by STML tag name ('pagina', 'navigator', 'libro'), so layout can build a screen from a description without knowing every widget type (up to 32 kinds). Each entry has a factory and an optional init that registers the widget's commands. Pointers are passed as void* to avoid circular includes, cast back inside the factory. Used by concha and layout.
