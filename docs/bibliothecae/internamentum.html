internamentum

chordae internatae (string interning)

String interning: one canonical copy of each distinct string, so equal strings become equal pointers and comparing them is a pointer comparison. A process-wide table (internamentum_globale) is shared by every library and created on first use with its own piscina; private tables exist for special cases. Two things to know: the empty string is never interned (NIHIL comes back), and actio, insula and stml rely on that as a refusal, so json keeps its own canonical empty key; and an interned string lives as long as its table, which for the global table means the life of the process (see the json audit of 2026-10-02).
