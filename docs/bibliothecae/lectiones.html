liber lectionum: quod processus legit, quaesivit,

The read log: when FABRICA_LECTIONES names a file, every read, existence check, directory listing, write and environment lookup the house's own file functions perform is appended as one line ('<letter>\ <path>'), with a single O_APPEND write so parallel children keep whole lines. Unset, it does nothing at all. fabrica turns these logs into verified footprints, so an action declared lectiones="verum" is judged by what it really read rather than what someone listed, and can then safely run in parallel. This module alone writes the log; filum, via_existit, iter_directoria and aedilis's directory walks call it, and tools/lectiones_lint.sh finds calls that bypass it. Fabrica plan 2, October 2026.
