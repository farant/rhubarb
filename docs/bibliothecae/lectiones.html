lectiones

liber lectionum: quod processus legit, quaesivit, exstare confirmavit, enumeravit, scripsit (fabrica slice 2).

The read log: when FABRICA_LECTIONES names a file, every read, existence check, directory listing, write and environment lookup the house's own file functions perform is appended as one line (a letter for the kind, a tab, the path), with a single O_APPEND write so parallel children keep whole lines. Unset, it does nothing at all. fabrica turns these logs into verified footprints, so an action declared lectiones="verum" is judged by what it really read rather than what someone listed, and can then safely run in parallel. This module alone writes the log; filum, via_existit, iter_directoria and aedilis's directory walks call it, and tools/lectiones_lint.sh finds calls that bypass it. Fabrica plan 2, October 2026. Two transitional shims, lectiones_fopen and lectiones_stat (10-06), let the raw stdio and stat calls that remain be recorded with a one-word change; 57 such calls stood in the closure of the root tests when a whole suite first ran under the log. Paths under /dev/ are deliberately not recorded: a device is not an input, and the judge cannot seal one, so a verdict that read one could never be reused.
