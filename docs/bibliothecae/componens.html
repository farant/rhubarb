componens

Arbor componentium: nodus LOGICUS (mores, non formae)

The logical tree of a ludus UI: each node says what something IS and how it behaves (id, action name, accessible title, kind (partes: button, field, option, list, item, dialog, title, image, table), bounds in its parent's space, focusable, clip, translation and scale, children) and nothing about how it looks. The hit predicate escalates from rectangle to polygon to mask to the component's own test. One of two trees that are never fused: componens says WHAT, figura says HOW IT IS DRAWN, and targeting, focus and capture walk only this tree. Strings are interned, so callers pass any literal. Serializes to and from STML and compares structurally, which is how tests pin a tree. Built each frame by a Componere function from the program's state (see dispensator); used by pictor (pictor_componentia) and the test toy.
