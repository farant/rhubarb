THESAURUS contentorum (fabrica plan 2 T3, spec 2

A content store for the build (fabrica plan 2): blobs by SHA-256 of their contents, actions mapping a key to the seals of their outputs, and generations recording which keys a run used, so old ones can be purged. Files and seals only, no SQLite, so any house tool can use it. Writes are atomic (temporary name, then rename), an existing blob or action is never rewritten ('never rewrite the unchanged'), and reads are verified by sampling, a broken blob being deleted rather than trusted. Purging is unsafe while a writer runs, so it happens under bin/fabrica's lock. It backs aedilis's extraction records and bin/compilator's object cache; building it found a real race in mkdir -p under two concurrent writers. October 2026.
