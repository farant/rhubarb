imago

imagines e filis legere (image loading, decoding)

Loading images: decode a file or a memory buffer (PNG, JPEG, BMP, TGA and the rest) into an Imago, RGBA in an arena, with a named error on failure; and read just the width and height from the header without decoding a pixel. The decoder behind it is the vendored stb_image (lib/stb_image.h), hidden behind this header and the house's one remaining image dependency: the no-dependencies page lists it as to be retired, not urgently. Decoding is the hard direction (every bit depth, palette, interlacing and filter), which is why the house wrote an encoder first. Used by specimen (screenshots), tessera's image tools, saltuarius and briar.
