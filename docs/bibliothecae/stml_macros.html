stml_macros

STML's macro and template layer, as pure tree-to-tree projections at load time: read, then expand, then distribute, then use. The file keeps its macro form and the original tree stays untouched and queryable. Expansion fills parametrized fragments (<#f p="@p">...</#> called as <<#f p="123">>), resolving calls only to earlier definitions so that it always terminates; distribution dissolves wrapper elements into typed items; strict matching compares a template against a candidate and captures what it binds. Every failure is one of some thirty named errors, the first found wins, and none is ever papered over. canon, the markdown-to-HTML path, oratio, silva and the stml tool run it.
