macho

Parsing Mach-O, the macOS executable format: single-architecture images and fat binaries, little-endian only (big-endian detected and refused), load commands walked with an iterator, the processor type and 64-bit flag. Two levels of API: the file (which may hold several images) and one image. One of the house's earliest libraries (2025-11-11), from the binary-inspection work; sectio and symbola build on it, and today mostly their tests use them.
