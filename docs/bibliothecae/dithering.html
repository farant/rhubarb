dithering

Reduces a colour image to the 16-colour Aquinas palette with Atkinson error diffusion, the algorithm Bill Atkinson wrote for the original Macintosh: in colour mode by nearest colour in RGB, or in grey mode by luminance thresholds. The caller chooses which palette colours are allowed, with presets (all, greys, warm, cold, black and white), and gets one palette index per pixel, convertible back to RGBA. It carries the palette table and the colour names. From January 2026; delineare has its own dithered gradients for drawing. Used by the image import view and tessera's effigies tool.
