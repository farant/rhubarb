argumenta lineae mandati (CLI argument parser)

A command-line parser in the builder style: declare flags (-v / --verbose), options with values (--output=x, --output x, -o x) and positionals (required before optional), set a description and examples, then parse argc/argv. Help text is generated from the declarations. Two parse modes: fatal (prints the error and exits, the normal case for a tool) or argumenta_conari_parsere, which returns NIHIL and lets the caller report. Everything is allocated from an arena. From the first months (2025-11); used by tools such as aedilis, silex, sputnik and generare. Many newer house tools take single-dash Latin words (-scribere, -siccum) and do not use it.
