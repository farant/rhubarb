quaerere

Fuzzy String Matching (fzf-style)

Fuzzy string matching in the style of fzf: the query's characters must appear in the target in order but not necessarily together, and a match is scored with bonuses for consecutive characters, word boundaries, the start of the string and exact case, minus a small penalty per gap. It can test a match, score one with the matched positions, or filter and sort a list of candidates; case sensitivity is optional, with a 'smart case' default. Today only its own tests use it.
