eventus_cauda

Cauda eventuum fontis: anulus + onera per lectionem

The event queue every input source fills: a ring of 256 events plus side tables for their payloads (committed text, coalesced mouse samples), so an Eventus stays a small value whose text points into the queue. Payload tables are cleared only when a read starts on an empty queue, so events not yet taken keep their payloads. Mouse moves coalesce: a move that matches the last unread one (same button, modifiers, pointer) turns that one's position into a sample and replaces it, so a burst becomes one event with its path. A full queue drops and counts (amissa); full text is truncated and flagged. eventus_residuum_integrare keeps the fractional part of scroll deltas so slow scrolling is not lost. The queue never stamps time; the source does. Pure, shared by the window today and the terminal source in eventus phase B.
