iter_directoria

directoria ambulare (directory walk)

Walking directories: an iterator over one directory (name, kind: file, directory, other, unknown; size), and a recursive walker with a filter (kinds accepted, a * and ? name pattern, maximum depth, hidden files or not) that calls a function per entry. Everything from an arena. Used widely (crusta, the ledger, silex, hospitium, saltuarius, silva's tools, the Gutenberg tools). One caution is recorded elsewhere: the walker uses stat, so it follows a symlink to a directory into it, which is why filum_arborem_delere does its own walk with lstat.
