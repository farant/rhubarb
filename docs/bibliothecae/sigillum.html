sigillum contenti (SHA-256, FIPS 180-4)

SHA-256 as a content seal: the hash used where a hash IS an identity, so collision resistance matters (friatio's hashes only spread keys across a table). One-shot or incremental, lowercase hex output, equality, and HMAC-SHA256 for signing requests (AWS SigV4, for example). It is everywhere identity is content: the ledger, fabrica's digests, briar, silex, silva's differ, volumen, sententiae. The header notes its name was never formally sealed.
