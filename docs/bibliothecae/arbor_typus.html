arbor_typus

arbor v1's type resolution, a separate pass after parsing: primitive, composite (pointer, array, function) and aggregate (struct, union, enum) types, typedef resolution, scopes for local variables, and the type of an expression. The 2026-08-20 archive analysis found its tests (with arbor_index's) still 'holding bars for milestones that have not happened', targets the newer parser had not yet reached, so they are to be archived, never deleted.
