interpres_terminalis

Lexemata terminalis -> Eventus (eventus B2)

Turns terminal tokens into Eventus, purely: the decoder between series_terminalis and the event queue. Its rule is honest fidelity (Fran, 2026-10-02): what the protocol does not say is not invented. In the legacy protocol there are no key releases, no physical code where a sequence is ambiguous (Enter is Ctrl+M), and no Shift bit, since Shift cannot be told from Caps Lock; physical codes are set only where the sequence names a key (arrows, F1-F12). With the kitty keyboard protocol it reads press, repeat and release, every modifier, associated text and the physical key from the base layout, and the first kitty sequence teaches it the terminal's capabilities, announced as an event before the key. Timing (the ESC delay) belongs to the source, not here. Eventus B2, October 2026.
