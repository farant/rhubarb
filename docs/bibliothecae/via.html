via

viae: iungere, normalizare, nomen (path utilities)

File paths as chordae: join, normalize (resolve . and .., collapse //), make absolute against the working directory, and take apart (directory, name, stem, extension), with POSIX behaviour at the edges spelled out, plus tests for absolute or relative, existence, and the current directory. Everything allocates in a piscina and always uses '/'; the API was designed with a later Windows port in mind. aedilis, briar, git, http and uri among others build on it.
