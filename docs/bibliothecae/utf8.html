UTF-8 decodere et encodere (unicode, codepoints)

UTF-8 decoding and encoding as pure functions, with no allocation and no dependency beyond latina.h: decode one code point and advance, strictly (overlong forms, encoded surrogates, values above U+10FFFF and truncated sequences all return -1); encode one code point; the length a lead byte announces; the continuation-byte test; count code points; step forward or back one code point. json uses it to check that the bytes inside strings are valid UTF-8.
