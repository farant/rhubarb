sputnik_parser

sputnik's parser: a Pratt parser for operator precedence and recursive descent for statements (the same pairing arbor v1 used for C two months later), producing a uniform AST whose children are laid out per node kind (binary, unary, ternary, call, member and index access, assignment, array literal...). Everything in an arena. November 2025.
