eventus_stml

Eventus[] <-> STML: plagulae replay

Events to and from STML: the replay file format. One element per event with its kind, time and fields; key codes by their W3C names (KeyA, ArrowLeft, Unidentified for unknown); time written exactly up to 2^53 ms. Also the notary's format: each event with the component it reached and the point in that component's space (eventus_notata_*), which manus_ludus replays and checks for divergence. The oldest of the eventus helpers (2026-09-04, ludus T5); used by the conformance tables, the notary probationes, and tools/auscultator.
