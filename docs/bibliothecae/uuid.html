uuid

UUIDv7 ordine temporis (unique identifiers)

UUIDs: version 7 (48 bits of Unix milliseconds, then random bits, so they sort by creation time) and version 5 (a SHA-1 of a namespace and a name, so the same name always gives the same id), with a convenience for genus plus title that the entity repository uses to 'scaffold' an entity idempotently; parsing, formatting (36 characters), validation, and the timestamp back out of a v7. From November 2025, for the first generation's entities and relations; the house's later identifiers are moneta's ULIDs.
