fons_6x8

The house's bitmap font: 256 characters of 6x8 pixels, one byte per row with the left pixel in the high bit, merged from the HP 100LX palmtop's font and one called Alcuin (which supplies the control symbols and the 0x80-0x9F range), so the window's text has the look of an early palmtop. The cell it defines is the window's modulus (6 x 8), which is why tessellatio's terminal cells default to the same size.
