agmen

Arithmetica integra per agmina (SIMD), EXACTA

Exact integer arithmetic over arrays, written so that the compiler turns it into vector instructions (SIMD; NEON on arm64). The name means a column on the march, a line advancing in step. Slice one (2026-10-09) is modular arithmetic for an odd modulus below 2^31: elementwise add, subtract and multiply, the elimination kernel exitus += c a, and the dot product, on canonical residues, with no allocation, and bit for bit equal to the scalar path, congruentia serving as oracle. Integers only: under vectorisation floating point would change its rounding. Multiplication is Montgomery's with R = 2^32, which for p < 2^31 fits in 64 bits (C89 has no 128-bit product), and its constants live in a handle, AgmenModulus, computed once. The first version had hand-written NEON; measured, it beat clang's own vectorisation of the same plain C by only 1.0 to 1.2 times, so by the rule agreed beforehand (a kernel stays hand-written only if it beats plain C) Fran had the intrinsics removed, and the API, array-level from the start, did not change. Speed is then an invisible property, since every correctness test would stay green while it halved, so the gate agmen-vectorizatio compiles the file and goes red if a marked kernel loop stops being vectorised, or if any other loop is. Against congruentia's remainder the kernels are about 2.4 times faster for multiplication and 5.8 times for the dot product (M2, 4096 elements). No library consumes it yet; it waits for a real modular workload such as a multimodular determinant.
