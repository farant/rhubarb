stml_html

Turns an STML document (after expansion and distribution) into HTML. There is no tag vocabulary and no translation table: tags belong to the author, and the emitter only handles syntax, adding the doctype, writing void elements bare and every other element as an open and close pair, escaping text but leaving written attributes raw, and passing <crudum!> bytes through as they are. It never judges whether the HTML is valid. What it cannot express (processing instructions, unresolved transclusions, dotted names, script or style without the raw marker, ambiguous entities) it refuses by name, with nothing partial. A second entry point renders a fragment without the doctype. The stml tool is its user.
