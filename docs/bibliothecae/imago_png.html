imago_png

imaginem in PNG codificare (PNG encoder)

A PNG encoder of the house's own, portable and dependency-free: it stands on flatura (DEFLATE) and flatura's CRC-32 alone. Before it, AppKit encoded PNGs in two places (vitrea and a tool), because there was no portable home for 'RGBA to PNG'; the header's point is that the platform boundary belongs to capturing pixels, not to the file format. Output is fixed: 8-bit RGBA, no filters, no interlacing, one IDAT, and DETERMINISTIC (the same image always gives the same bytes), which tests need. Filters would shrink files and can be added later without changing the interface (Eskil's rule, cited). Encoding only; decoding stays with imago and stb_image, a deliberate asymmetry since a decoder must read every variant. Errors are named, never silent. Used by icones, specimen and vitrea's screenshots.
