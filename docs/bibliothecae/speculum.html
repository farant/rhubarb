speculum

Modus-debug se-fontis pro apps vitreis

A self-source debug mode for vitrea apps: the binary carries its own source (a capsule generated at build time), and pressing Cmd+Shift+D injects an overlay that shows it, through one bridge method returning provenance, sources, documents and exclusions. The injected stub heals itself: if the page has reloaded, the whole injection runs again, so C keeps no state about the page. Sources are inflated lazily on first request. Used by forum, villa and atrium. Spec project-specs/speculum-spec-v2.md (July 2026).
