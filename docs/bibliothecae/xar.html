xar

tabula crescens segmentata (growable array, vector)

The house growable array: segments that double in size, so elements never move. A pointer or index to an element stays valid as the array grows, and nothing is ever reallocated or copied. It lives in a piscina (destroying it is a no-op) and gives constant-time indexing, append, swap-remove and pop, a stable merge sort, linear and binary search, and an iterator. The catch is stated in its first line: segments are not contiguous, so never read xar_obtinere(x, 0) as a flat C array; iterate, or copy out with xar_copiare_ad_tabulam. The ordinary table holds about 33 million elements, xar_creare_magnum more, and an append past the limit is refused by name rather than truncated.
