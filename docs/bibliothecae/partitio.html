partitio

Partitions of rows into groups, for oratio's evaluation: groups are numbered in order of first appearance (the canonical numbering), so equal partitions have identical tables and every group has a representative row by which a reader can name it. Built from arbitrary labels or from cells with equal bytes; unequal row counts are refused, never truncated. Translated (not vendored) from knotapel's scrutinium, keeping an O(n) refinement and a width bound and dropping the rest. September 2026.
