vim

A vim command interpreter as a pure function: give it the editor state and a key, get the new state back, with no window and no drawing, so it can be tested on a grid built from a string. Normal, insert and visual modes, special keys as negative codes, a clipboard of up to 32 lines shared between editors, and an undo stack of 32 operations that covers line operations only (dd, o, O, p, P, dG); character edits are deliberately not undoable. The state records whether the text changed and whether ESC in normal mode asked to close. The first generation's clearest example of separating logic from display (2025-11-28).
