postulata_posix

postulata platformae pro superficie POSIX

A preprocessor seam for POSIX: glibc under -std=c89 hides POSIX declarations unless a feature-test macro is defined before the first system header, while Darwin and musl are permissive, so without this header POSIX-using files fail on Linux (tcp_posix.c: 20 errors from 4 hidden roots, measured). A Docker probe on 2026-08-03 (glibc 2.35 and musl 1.2.5, six files in five variants) settled on _DEFAULT_SOURCE, which fixes everything fixable in both libraries and does nothing on Darwin; the stricter variants are worse (_XOPEN_SOURCE 700 and _POSIX_C_SOURCE hide usleep again). The rule, enforced by examen (code 85): it is the FIRST include of any POSIX-using file, before its own header and before latina.h, because glibc fixes its feature set on the first system header touched.
