atrium

A complete vitrea application with the batteries included: window, capsule, web view, RPC bridge, debug mirror (speculum), remote control (imperium's vivarium) and the right destruction order, set up by one call. The problem was measured: forum, villa and mensor's UI each hand-copied the same ~65 lines, with the web-view configuration identical letter for letter, and each had picked up a different subset of the tools by accident (forum and villa had speculum and not imperium, mensor's UI the reverse). The app keeps its own loop, with no inversion of control: it calls atrium_gressus each turn and can break, print or set a breakpoint as usual. The per-step arena is reset at the START of each step rather than the end, so nothing needs pairing and values last until the next step. Kept outside vitrea, whose scope stays minimal: including atrium links hospitium, speculum and imperium whether used or not, the declared price. Used by mensor's UI and briar's spectator (2026-08-13).
