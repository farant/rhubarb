organum_canon

textus organum.canon infixus (status-plan S1).

The text of organum.canon, the schema that judges widget manifests, embedded in the binary so that the loader never reads a file. One function returns a copy of the text. The body, lib/organum_canon.c, is generated by tools/organum_canon_infigere.sh from the canon at the repository root and is never edited by hand; the build layer has a generator action for it, so the committed file is judged against the generator's output. The pattern is norma_canon's, and the worklog notes that with two users a single generic embedding script is due. Written 2026-10-10 with organum, its only consumer.
