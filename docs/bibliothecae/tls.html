Bibliotheca TLS (Transport Layer Security)

Encrypted connections behind a platform-neutral header; today the implementation is macOS's Security.framework (lib/tls_macos.m), with BearSSL named as the candidate for other platforms (see the no-dependencies page). Connect with SNI and certificate verification, send, receive with the same contract as tcp (0 = closed, ONLY then; TCP_ITERUM = timeout), and read the peer's leaf certificate (validity dates as Unix epoch, subject), 'the world's view': what the host actually presents, not what is on its disk; added in July for villa's certificate-expiry check. The worklog holds the house's sharpest network bug: HTTPS bodies over about 4 KB came back as success with a fraction of the bytes, differently each run, because a TLS record straddling two TCP reads made SecureTransport report would-block with 0 bytes, and 0 was passed up as 'closed'. Found by instrumenting every read (lapide bugs 015/016, 2026-09-26); the old live test only asserted that something arrived.
