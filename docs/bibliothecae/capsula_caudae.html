capsula_caudae

Tail-Appended Asset Embedding Library

The same capsule format appended to the END of an already compiled binary instead of compiled into it, so there is no compiler limit on size (gigabytes are possible): the original executable, then a header, a table of contents, a string table and the compressed files, then a 16-byte footer holding the offset and the magic 'CAPSCLDA'. The program opens its own argv[0] and reads files by path through an API kept close to capsula's for easy switching. A tool appends the assets (tools/capsula_caudae_adiungere). December 2025.
