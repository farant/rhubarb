SYSTEMA DIMISSIONIS (status-plan S5c; census XIII):

The dismissal system: fields that a manifest marks with the aspect popover are closed by the framework and no longer by each widget's own code. Written 2026-10-10 (status plan S5c), and the first system that sits in the path of input, where persistence and references only react afterwards; for it the dispensator gained one pair of hooks, before an event is sent and after an action has consumed one. The rules are Fran's decisions. Esc closes the open popovers of the active branch and is consumed. A mouse press outside the popover's own subtree closes it, swallowed if it lands in the same widget and passed on if in another, except that a press on the control that opened it is left alone, since that control toggles or switches by itself. A successful action on a component marked as closing closes them too. One rule was corrected by the regression suite: Esc during a drag inside a popover must cancel the drag first, so a gesture in flight takes Esc before the popover does. With it pictor lost the calls that closed its palette by hand. A planted fault that removed the opener's exemption survived the toy suite and was caught only by pictor, which has two palettes to switch between: a toy can miss a rule whose value shows only with two of the same thing. Stated assumption: one popover per widget. Bound by pictor and by vicus.
