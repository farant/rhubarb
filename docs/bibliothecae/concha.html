concha

The shell that owns everything a first-generation app needs: arena, interning, persistence (a log file, or memory), the entity repository, the widget context, the command and widget registries, the ten screens, the window and its pixel table, and the event loop. Built-in widget types and the $date command are registered automatically; an app adds its own commands and runs. Its only caller today is probatio_combinado, a demo program kept among the tests, which starts the whole first-generation application with its log in data/combinado.log. The newer apps (pictor, villa, forum) do not use it: pictor is built on ludus.
