importatio_visus

Import preview widget

The preview half of image import: holds the import session (the source image, the palette colours enabled, the breakpoints, colour or grey mode), runs the Atkinson dithering again when a setting changes, and draws the result with zoom and pan. The dialog (dialogus_importatio) holds the controls and asks this for the final palette indices. From January 2026. Since 2026-10-03 its wheel step comes from the event source's capabilities, 16 pixels in a window and a cell's height in a terminal, in place of a fixed number.
