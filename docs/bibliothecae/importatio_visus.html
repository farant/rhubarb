importatio_visus

The preview half of image import: holds the import session (the source image, the palette colours enabled, the breakpoints, colour or grey mode), runs the Atkinson dithering again when a setting changes, and draws the result with zoom and pan. The dialog (dialogus_importatio) holds the controls and asks this for the final palette indices. From January 2026.
