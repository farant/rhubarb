mensa (tabula cogitationum): status tabulae persistens

The C half of a 'table of thoughts' for vitrea apps: nested desks, draggable cards and notes whose positions persist between sessions. It registers two generic RPC handlers any vitrea app can mount, mensa_status (the folded current state) and mensa_actum (record one event), and stores every event in a volumen; the state is a fold of the events by id, with a delete event removing one. Event-sourced, so history and undo come for free later. A building block, not an app. Name sealed 2026-08-04; used by silex.
