Modulus stratus delineandi: cellula in pixelis nostris

The unit of the drawing layer's geometry (Vitruvius's modulus: the unit every measure derives from): the size of a cell in 'our pixels', the size of the surface, and a reserved screen ratio, kept as exact rationals with no floats. Three spaces: cells, our pixels (the coordinates of Mandata), screen pixels. The target declares, the host chooses: a window's cell is its font (6x8); a terminal takes any. Text is measured per target: the window font draws every rune in one cell (ASCII and Latin-1 only, the rest as tofu), a terminal uses rune units where wide ones take two, so '中' is 6 pixels in the window and 12 in the terminal. C89 leaves the rounding of negative division to the implementation, so floor and nearest are computed by hand (negative coordinates arise from translation and clipping). Pure, no allocation; bad inputs degrade (a cell <= 0 becomes 1), never break. Built 2026-10-01 for tessellatio; delineare_mandata uses it too.
