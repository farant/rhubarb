Visiones operum

Every project vision so far, grouped by domain

The items classified as project vision (one thing that should exist) across the extracted visions, kept up to date as more sources are read. A domain is a field of work, not a project: one project's visions can fall in several domains, and one domain gathers several projects. Each item links to its source page; highlighted items are ones Fran selected. Sources so far: Brighton (B), Tabularium (T), Text stack (X), Silva instrumenta (S), Exemplar programmandi (A, a ledger vision record). 112 items.

The domains are Claude's provisional grouping (2026-10-02), to be renamed, merged or split.

Status from the ledger inventory visiones operum (status): 2 built, 33 partly built, 75 not started, 2 unknown; 9 with a pivot note.
