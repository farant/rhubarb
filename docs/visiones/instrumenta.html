I. The seed: extension without extension

III. The three lanes

  • S11One input, three consumer kinds told apart by their verification contracts: checking (query → verdict), code generation (query → new trees), refactoring (query → mutation of code the tool does not own) L127-152 Load-bearing decision
  • S12Code generation here is post-typing: Rust's proc macros run before name resolution, while a silva derive reads field types with their offsets L138-142 Occasio

  • S13The cog pattern with byte-exact roundtrip: the generator owns the bytes between its markers, regeneration is idempotent and diffable, and origo traces generated code back to the annotation that produced it L145-150 Project vision
  • S14Coccinelle proved pattern→template transformation over C at kernel scale, limited exactly where silva is strong L153-157 for S16Fits no tier: precedent

  • S16Refactorings are executed against the corpus before a human sees them: transform → re-type → interpret affected suites → compare stdout with the goldens L161-167 Project vision
