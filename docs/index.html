Rhubarb

Liber de opere toto: the vision, the pieces that serve it, what remains

A book about the whole repository, organised by purpose rather than by module: each part says what the vision is, which pieces serve it, which decisions it forced, and what is still unbuilt. It is written in editions, not by accretion. This is the first page of the first; for now it holds the visions as they are extracted from project-specs/, one source at a time.

Project-wide commitments: kept or broken, across every project (see Taxonomiae). Each may grow its own page.
